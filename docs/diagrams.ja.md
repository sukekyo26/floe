# 図

`diagram` の部品は、節にも `details`・`tabs`・`columns`・`entries`・`checks`・`options` の項目の `parts` の中にも置ける、その場に書く spec です。キャンバスと、その上に絶対座標（左上が 0, 0。どの座標も ± 100 万まで、大きさは 100 万まで、キャンバスは 1,000 万まで）で置く部品から成ります。ページを描く前に確かめ（誤りはデータファイルの行と列で言う）、inline SVG で描き、原寸より小さく描かれた図は拡大できます。`floe diagram render` は、ファイルに書いた spec を同じように描きます（`floe diagram render --help`）。

```yaml
- diagram:
    width: 640
    height: 200
    # スクリーンリーダーが読み上げる
    title: API の配置
    parts:
      - frame: { x: 16, y: 16, w: 608, h: 168, label: VPC }
      - box: { name: alb, x: 40, y: 72, tone: accent, rows: [[ALB, main code], 公開の入口] }
      - box: { name: api, x: 400, y: 72, rows: [API サーバー, ECS] }
      - edge: { from: alb, to: api, label: HTTPS }
```

- `width` と `height` は、それぞれ省けます。省くと、キャンバスは描いたものの右（下）の端まで広がり、さらに 20 空けます。左上は 0, 0 のままなので、座標は書いたとおりです。`raw` の SVG は測らないので、`raw` を使う図は `width` と `height` を書きます（書かないと切れることがあります）。
- ほかの鍵の代わりに `example: <種類>` を書くと、組み込みの見本を描きます（`floe diagram example` が並べる）。ページは図だけを見せ、spec は見せません。見本の spec を読む・写すときは、`floe diagram example <種類>` で出します。
- 文（`title`・行・ラベル）は、文か、言語ごとの言葉（英語を含む）です：`{ en: Store, ja: 保存先 }`。図の `title` は、図を見られない読み手に伝える字なので、どの言語でも空にできません。ラベルの字（`label` の鍵すべて（graph の線とまとまりも）と、部品 `label` の `text`）は、どの言語でも空にできません。ラベルを描かないなら、鍵を書きません。ページは `lang:` の言葉を描き、spec は書いた言語ごとに並べて確かめます。
- 図は、枠の中にページの地 `--bg` を塗ります。下の線を隠すもの（ラベルの下の四角、白抜きの端と点）も、その地で塗ります。白い面や、模様のあるテーマのページの上では、図はページの地の色の箱になります。
- 部品は、種類を名指す鍵 1 つで書きます。`floe part show diagram schema.json` がすべての鍵を出し、`floe diagram example <種類>` が種類ごとの spec を、格子を説明するコメント付きで出します。

## 図の 2 つの書き方

図が何のためかで選びます：

- **手書き**：絵として読む図（構成図・配置図など）で、置き場所が大事なとき。何をどこに置くかを決められるので、主な流れをまっすぐ通し、同じ仲間を揃え、ラベルを線の上に置けます。書く量はいちばん多く、部品を動かすと、その部品の位置を写したもの（囲む枠、位置を写した線の `via` と `at`）も動かします。線の写しは、選んだ曲がり角だけを書けば避けられます（[手で書く線](#手で書く線)）。上の例はこの書き方です。
- **`graph`**：流れ、状態の遷移、下書き、よく変わる図、つながりの多い図。何と何がつながるかを書くだけで、足すときも座標は要りません。置き場所は floe が決め、手で置くより場所を取ります。ページより広い図は、拡大するまで縮んで見えます。同じ spec でも、片方の `direction` がずっと良くなることがあるので、両方を試します。例は [graph](#graph) にあります。

### 手書きで、floe に断られずに書く

- 箱には `x` と `y` を書きます。`w` と `h` を省くと、箱は字に必要な大きさになります。箱を揃えたいときに書きます。`w` が小さすぎると、要る幅を言って断られます：`box "a": "A long title here" needs w: 174 or more`。`floe diagram inspect` は floe が決めた箱の大きさ（`box "alb" 240,90 144x29`）を出すので、次の箱はそれを見て置きます。
- ラベルのある線の箱の間は、ラベルの幅以上にします。幅は `floe diagram inspect` の `label` の行が言います（`label "HTTPS" 80,5.5 46x18` の 46）。足りないと `box "a" overlaps label "HTTPS"` と断られます。
- 箱は、枠の中にまるごと、または外にまるごと置きます（`box "a" straddles the edge of frame "F" at x 100, spanning 80 to 160`）。枠の見出しの下の端より下に置きます（`box "a" overlaps the heading of frame "Frame label"`）。
- 線は、両端の名前を `{ from, to }` で書くと、floe が通します。間に箱がある線は断られます（`edge "a"→"c" runs through box "b"; move one of them, or go round it by via`）：箱を動かすか、`via` を書きます（[手で書く線](#手で書く線)）。
- 部品を数個書くごとに、データファイルに `floe diagram inspect` を実行します。各部品の置き場所と、断った所を、直す行つきで出します。

## graph

`graph` には、箱のつながりだけを書きます。置き場所は floe が決めます：

```yaml
- diagram:
    title: ページが公開されるまで
    parts:
      - graph:
          x: 20
          y: 20
          nodes:
            - box: { name: write, rows: [データを書く] }
            - box: { name: check, shape: hex, rows: ["検査を通る？"] }
            - box: { name: show, rows: [ページを出す] }
          edges:
            - { from: write, to: check }
            - { from: check, to: show, label: "はい" }
            - { from: check, to: write, label: "いいえ" }
```

### 段

- 箱は、線が来る箱より下の段に置きます（輪を作る戻りの線も、書いた向きのまま描きます）。ただし、`level` と書いた線（下）の 2 つの箱は同じ段に立ち、`with` を書いた箱（下）は相手の段に立ちます。段の中の箱は、線の交わりが少ない順に並べ、交わりが無ければ書いた順のままです。同じ spec は、いつも同じに並びます。
- 箱とアイコンの `with: <名前>` は、線を描かずに、名前の箱かアイコンと同じ段に立てます。別のまとまりの箱とも書けます。線が来る箱より下に置きたくない箱（使うサーバーより下へ行くゲートウェイなど）や、まとまりの枠を最初の段から始めさせたくない箱に書きます。線は図の意味のまま書きます。`nat` に `with: alb` と書けば、`api → nat` は `api` から上へ引かれます。

  ```yaml
  # fragment
  - icon: { name: nat, with: alb, icon: aws/res/amazon-vpc-nat-gateway, label: NAT }
  ```

- `with` が段から外すのは、箱からその箱へ入る線だけです。その線は段に合わせて上か下へ引かれ、同じ段になれば断ります。まとまりからの線、`level` の相手へ入る線、その箱から出る線は今までどおり段を決め、名前の箱ごと動きます。それらでできた輪の戻りの線は書いた向きのまま描き、どの線が戻りになるかは書いた順で決まります（箱を書く順を替えると替わります）。
- `with` は線で繋がっていない箱を一緒に並べます。その間に書いた、どちらとも線の無い箱は、その外に立ちます。線で繋がった箱の順は変えません。

### 線の端

- 線は、箱の辺の別々の点から、形の輪郭の上で出入りするので、2 本の線が同じ所を通りません。線の多い箱は広くなります（`right` では高くなります）。1 つの辺に来る n 本の端は、辺を n+1 等分した点に、相手の並びの順に立ちます（1 本は真ん中、2 本は 3 等分、3 本は 4 等分）。まっすぐな線はまっすぐのままで、両方の辺に入る点か今の線の上に残り、同じ辺のほかの端はその周りに等しく立ちます。何かに当たる、交差が増える、ほかの線のすぐ脇を通る、線を両端のどちらも入っていない枠の中へ入れる端は今の場所のままです。箱の輪と `level` の線は数えず、動きません。同じ graph の線どうしは交わってよく、graph の線とほかの部品は、ほかの線と同じく確かめます。
- アイコンは、線が何本あっても 48 の正方形のままです。1 つの辺に来る n 本の線は、辺を n+1 等分した点で、相手の並びの順に終わります（1 本は真ん中、2 本は 3 等分、3 本は 4 等分）。辺はアイコンの辺で、下の辺だけは、名前の下から出ます（名前の幅の外なら、アイコンの下から）。まっすぐな線に合わせて、アイコンは段に沿って 1 回だけ少し動きます。それで足りないとき、辺に 1 本だけの端は、点から最大 12 ずれて立ちます（大きさ 24 以下のアイコンではずれません）。まっすぐ点に届かない線は曲がります。ラベルが無ければアイコンとアイコンの間で 1 回、ラベルがあれば、線が乗らない方のアイコンのすぐそばで曲がります。アイコンのすぐそばでは、2 本の線が短い区間を共有して、後に描いた線の見た目になることがあります。線が多いと点が近づき、5 本で矢じりが隣と触れ、8 本で重なります。`x`・`y` を書いた部品 `icon` は今までどおり手の配置で、線は辺の真ん中で終わります。

### ラベル

- 線の `label` があっても、graph の段と並びの順は変わりませんが、大きさは変わります。線を引いた後に、ラベルは線の上に、図の地を敷いて線を切って立ち、場所が足りなければ図が広がるので、ラベルのある graph はラベルの無い graph より大きくなり、箱の場所も変わります。置く所は、線のいちばん長いまっすぐな区間の真ん中で、区間の両端を 12 ずつ残します。そこに何かあれば区間に沿ってずれ、次に長い区間へ移ります。どの区間にも場所が無ければ、floe が場所を作ります：線を足りない分だけ伸ばし、隣の線を押し離し、そこで図を広げます（箱が広がることもあります）。どれも線を曲げません。自分に戻る線のラベルは、箱の外側の線の脇に、地なしで立ちます。ラベルの場所はいちばん広い言語の字で決めるので、どの言語でも同じに並びます。graph の `x`・`y` は、ラベルも含めた全体の左上です（1 列の内の差はあります。ラベルが箱より広かったり上に出たりすると、箱の格子を保つために、graph を 1 列の倍だけずらします）。そのため、ラベルで graph の箱が下にも横にも動き、脇に手で書いた部品に重なるようになることがあり、そのときは手で書いた部品に誤りを言います。手で書いた枠とラベルは比べないので、ラベルは枠の線と交わる所で枠の線を切ります。

### まとまりと帯

- `group` は、中の箱（入れ子のまとまりの箱も）を、どの段でも隣どうしに並べ、間にほかのものを入れません。floe はまわりに部品 `frame` と同じ枠を描き、`label` は枠の左上の見出し、`accent` は frame と同じです。枠はまとまりの箱とその間の線を囲み、ほかの箱を囲みません。中の箱と外の箱の間の線は枠の辺を横切ります。両端がどちらもまとまりの外にある線は、段の並びのままだと枠の中を通る所で、枠の外を回ります。枠から 1 列離れ、要れば段の向きに逆らって戻るので、線は長くなり、交差が増えることがあります。小さな図でも、回る道が無いとき、箱の 1 つの辺に多くの線が着くとき、混んだ図で floe が探すのをやめたときなどは、枠の中を通ることがあります。レーンは回りません（2 つのレーンの間の線は、その間のレーンを横切ります）。`level` の線は段の中でまっすぐのままです。回る道が見るのは graph 自身の部品だけで、手で書いた部品にぶつかると、手で書いた部品の方で言います。`label` はまとまりの始まりの段より上に立ちます。上から線の来る箱は `label` の右に立ち、線の来ない箱は、段の中で線の来る箱より前に並ぶと `label` の下に立ちます（段の順は書いた順で、交わりを減らすために floe が変えることがあります）。枠は `label` を収めるので、`label` が長いと、まとまりはその分だけ広くなります（`right` では始まりの段が高くなります）。まとまりの `name` は枠の名前で、手で書いた線の端にできます。
- まとまりへの線は枠で終わります。上の段からなら枠の上の辺で、そうでなければ枠の下の辺から出ます（`right` では左と右の辺）。線ごとに別の点で、見出しを避けます。まとまりと、それが持つ箱・まとまりの間の線と、まとまりから自分への線は断ります。まとまりの箱の間の段にある箱（またはまとまり）からの線（まとまりの箱のどれかがそれと同じ段か上に、別の箱が同じ段か下に立つ）も断ります。まとまりの中の箱で終えてください。
- `with` でまとまりの段の間に立つ箱からまとまりへの線は、ほかの箱と同じく断ります（上にも下にも立てないため）。文に従って中の箱で終えると、次の文が `with` を外せと言います。効くのは `with` を外すことです。
- `nodes` の代わりに `lanes` を書くと、並べたものがそれぞれ帯（レーン）になります。帯は、まとまりと同じく `{ name, label, accent, icon, nodes }` で書き、`group:` の鍵では包みません。帯は線の向きに graph の端から端まで（`down` では上から下まで、`right` では左から右まで）伸び、書いた順に 24 あけて並び、幅は中身の幅です。見出しの有る無しによらず、帯の上と下はそろいます。帯と、その中の入れ子のまとまりは、まとまりと同じです。ただし、帯は端にできません（帯の段の外から入る線は無いため）。帯の中の箱かまとまりで終えてください。

### level の線

- `level: true` と書いた線は、2 つの箱を同じ段に立て、向かい合う辺の間をまっすぐ結びます（`right` では、上の箱の下の辺と下の箱の上の辺の間。1 つの辺に線が 2 本以上あって、アイコンの辺の点が線の上に無ければ、曲がります）。線は、段を横切る向きの辺が短い方の箱の、その辺の真ん中から半列ずれ、同じ 2 つの箱の間の線は 1 列ずつ離れます（短い方の箱は線の分だけ伸びます）。
- 2 つの箱は、同じまとまりの中（どのまとまりにも入らない箱どうしも）か、別々の帯の直下に置きます。2 つの箱の左右（`right` では上下）は、段の中の並べ替えでなく、書いたものから決まります。同じまとまりの中で level の線でつながる箱は、書いた順に隣どうしに並び、別の帯への level の線を持つ帯の直下の箱は、その帯の側の帯の端に立ちます（両方の向きへ線を持つときは、帯の始まりの端）。
- そのため floe は、並べる前に次を断ります：まとまりを端にした level の線と、同じまとまりの中でも別々の帯の直下でもない 2 つの箱の間の level の線、level の線で同じ段に立つ 2 つの箱をつなぐ線、2 つの箱の間に何かが立つ線（同じ組で 2 つの間に書いた箱、帯の中で組の向く側に書いた箱、間の帯の箱か、その段にまたがる入れ子のまとまりの枠、どちらかの帯の同じ端に立つ別の組、始まりの端に立つ組の帯の、その段のほかのもの）、最初の箱の輪の辺を使う線。`right` では帯の見出しが最初の段に伸びるので、それを横切る level の線は、並べた後に断ります（見出しを短くしてください）。
- `with` で level の線の 2 つの箱の間に立つ箱は、ほかの箱と同じ文で断ります。文は動かせと言いますが、効くのは `with` を外すことです。
- `level` と書いた輪は、ただの輪です（箱はもう 1 つの段にあります）。手で書いた線は、輪の辺と同じく、level の線の使う辺を避けます。

### 輪

- `from` と `to` に同じ箱を書いた線は、その箱に戻る輪です。輪は graph の並び方を変えません（ただし、まれに、枠の外を回る線が箱の輪の場所を横切ると、図全体が floe の誤りで描けません。輪かまとまりを外してください）。線を引いた後に、段をまたぐ graph の線が使わない辺（右の辺。`right` では下の辺。level の線はこの辺を使えません）から出て、書いた順に、最初のものを一番内にして入れ子に描き、ラベルは一番外の輪の 1 列外に順に並べます。箱は輪とそのラベルのために、その辺に沿って伸び、floe はラベルと同じく場所を作ります。

### 手で書く部品と一緒に使う

- `level` にできない線（別々のまとまりにした 2 つのゾーンの間など）と、`with` で同じ段に立つ 2 つの箱の間の線は、graph の横に手で書けます。graph のものを動かさないので、線の端は、ほかの線が決めた段のままです：

  ```yaml
  # fragment
  parts: { x: 20, y: 20, nodes: [...], edges: [...] }
    - edge: { from: writer, to: reader, label: 複製 }
  ```
- graph の箱とアイコンと、まとまり・帯の枠は、手で書いた線の端にもできます。その線は、ほかの手で書いた線と同じく辺の上で終わります（下）。`fromSide`・`toSide` を書かないと、`via` の有る無しによらず、graph の線が残した辺のうち、隣の via（無ければ相手の端）がその外にある辺を、左右、上下の順に使います。残す辺は、箱とアイコンでは graph の線の端も輪も level の線も無い辺、まとまりと帯の枠では graph の線が端を置かず横切りもしない辺です。via がその外にある残す辺が無いときは、選んだ辺のままで、graph の線の上を走ることがあるので、graph の線が使わない辺を `fromSide`・`toSide` で書きます。輪や level の線のある辺は、それらのものなので、手で書いた線の端にしないでください。
- graph や tree が置いた部品と手で書いた部品の間の誤り（重なり、線が箱を通る、交差）は、動かせる、手で書いた方の行と列に言います。手で書いた部品どうしの誤りは、後に書いた方（`parts` の後ろの項目。同じ項目の中なら、比べた順で前のもの）の行と列に言います。tree の部品どうしと、tree の部品と graph の部品の間の誤りは、tree の部品のうち後に書いた方の行と列に言います。後から足したり動かしたりした部品が起こすことが多いためです。graph の部品だけが起こす誤り（2 つの graph の重なりや交差、キャンバスからはみ出す graph）は、graph の場所に、その `x`・`y` を動かすよう言います（キャンバスからはみ出すときは、キャンバスを広げることも）。

### 上限

- 1 つの graph の箱とまとまりは、入れ子を数えて合わせて 200、線は 400 までです。図の全部の graph の線が端と端の間で越える段は、合わせて 4000 までです。

## 手で書く線

`via` も辺も無い線は、相手に向いた辺から、直角に、曲がり 2 つまでで進みます。別の道にするには `via` か辺を書きます。アイコンの辺は、ラベルも含めた高さで選びます。アイコンのラベルは自分の線の障害物でもあります。線がその端のアイコンのラベルを通ると断られたら、`fromSide: right` と書くか、相手をラベルより下へ動かします。

`via` には線の道のうち選んだ所だけを書き、`at` は、ラベルが立つ線のいちばん長い区間の真ん中では困るときだけ書きます。`at` の無いラベルは、線が枠をまたげるので、枠の縁との検査を受けません。floe は、x も y も違う点の間に角を足し、最後の辺へ直角に入ります。足される角は書かなくてよく、部品の位置を写した数は、部品を動かすと書き直すことになります。点は片方の軸だけ `{ x: 710 }`・`{ y: 218 }` でも書けます。もう片方は前の点の値で、最初の点は線の始まりの中心の値です（点ならその点、dot はその中心、部品と行はその真ん中）。`{ x: 710, y: 218 }` は `[710, 218]` と同じです。

```yaml
# fragment
- edge: { from: api-a, to: queue, fromSide: top, toSide: left, via: [[965, 218]] }   # M640,350 V218 H965 V510 H990
- edge: { from: api-c, to: writer, fromSide: right, toSide: left, via: [{ x: 710 }] } # M664,646 H710 V374 H790
```

最初の点は、線が出る向きの軸で書きます。上下の辺からは `{ y }`、左右の辺からは `{ x }` です。`fromSide: top, via: [{ x: 150 }]` は箱の中心の高さを取り、箱を通るので断られます。`via: [{ y: 10 }, { x: 150 }]` なら上へ出てから横へ走ります。

次の点は省けません。省くと線は別の道になり、floe は望んだ道を知らないので、誤りは出ません。

- `fromSide` を書かない線の最初の点：線が出る辺を決めています。`fromSide` を書くか、片方の軸（`{ y: 10 }`）で残します。
- 点や dot から上下へ出る線の最初の点：点と dot は横へ出ます。片方の軸（`{ y: 120 }`）で残します。
- 来た向きと違う向きへ先に曲がる角：floe が足す角は来た向きを先に進むので、下へ来た後に横へ先に進むなら、その角を書きます。
- 線の最後の 1 つの点：`via` が無いと floe が道を決め、線は辺をほかの線と分けます。辺の真ん中に残すなら `via` を残します。

名前の端どうしで、`via` も `straight` も無い手で書いた線は、1 つの辺を分けます。1 つの辺に来る n 本の端は、辺を n+1 等分した点に、辺を出るときに交わらない順で立ちます（1 本は真ん中、2 本は 3 等分、3 本は 4 等分）。真ん中どうしをまっすぐ結ぶ線はまっすぐのままで、両方の辺に入る点か今の線の上に残り、同じ辺のほかの端はその周りに等しく立ちます。こうすると、ほかの線と交わる、箱やラベルや枠の見出しを通る、長さが無くなる線は、真ん中のままです。手で置いたラベルに当たる線も真ん中のままなので、分けたいときはラベルを動かしてください。`via`・座標の端・`straight` の端は、書いたとおりか辺の真ん中のままで、数えません。1 点から分けたいときは、`via` か `tree` で書きます。線にラベルを分け合わせたいとき（「検査」を参照）は、ほかの線と分かれてラベルから離れる線に `via` を書きます。dot・行・bar の線は真ん中のままです。向かい合う 2 つの辺に共通の高さ（どちらの端からも 12 内側）があって曲がる線は、その高さの中でまっすぐになります（向かい合う辺の間が矢じりの長さの 8 より狭いときは、曲がったままです）。同じ辺のほかの端は動きません。まっすぐな線が、部品・ラベル・見出しを通る、line・axis・箱と枠の縁・dot に 4 より近い、ほかの線と交わる・触れる・6 より近く並ぶときは、今のままです。こうして誤りが出るとき（場所を書いていないラベルが何かに当たる、など）は、その図の線はどれも今のままです。ラベルに `at` を書くか、当たるものを動かしてください。線が枠の `label` を通ると断られるので、`via` で避けます。

floe が自分で場所を決める区間（向かい合う辺の間の区間、同じ向きの 2 つの辺の外を回る区間、辺へ入る前の 2 回の曲がり）は、全部の部品を置いた後に、部品 `axis` の線（軸、`grid` の線、目盛り。目盛りのある軸の下は目盛りの先から）と、横か縦の部品 `line` の線から、4 以上離します。そうした線や、沿う部品・frame・dot・線から、ちょうど 4 離れた一番近い所（同じ近さなら上か左）へ、両端の印の内側で、外を回る区間は外へだけずらします。同じ線の上にあって、同じ点か同じ部品の同じ辺から出るか入る線は、一緒にずらします。どこへずらしても、書いた大きさの図からはみ出す、部品や字を通る、ほかの線と交わる、新しく通る所がそれらの線・部品や frame の縁・ほかの線の区間に 4 より近く沿う、ラベルの立つ区間が変わる、のどれかになるときは、ずらしません。線（edge）は、離す相手にはしません。1 つの部品へ入る線は、わざと区間を共有するためです。ただし、ずらした先がほかの線に沿うときや、dot の上に来るときは、ずらしません。`graph` と `tree` の線はずらしません。

`via` を書いた線で、辺を書かない名前の端は、隣の via の点（両方の軸を解いた後の点）がその端の外の横にあれば左右、上下にあれば上下の辺を使います（`straight` の線も）。点が斜めにあれば、直角の線の終わりの端は、線が来た向きの辺を使います。始まりの端と `straight` の線で点が斜めのときと、点が端の中や縁の上にあるときは、`via` の無いときと同じく相手の端に向いた辺を使います。表の行はいつも左右の辺で、dot は辺を持ちません。辺を書いた端は書いた辺を使います。直角の線の終わりの辺には、書いた辺でも選んだ辺でも、via の点がその辺の外側にあれば最後の区間が直角に入り、曲がり 1 つでは来た線を戻るときは、間の真ん中で 2 回曲がります。via の点が書いた辺の外側に無いときは、前の区間の向きのまま入り、端の縁を這うことがあるので、via は辺の外側に書きます。直角の線が via で斜めの次の点へ曲がるときは、来た向きのまま先に進み、それが来た線を戻るときは、もう一方の向きから先に進みます。

## 検査

- 箱に対して広すぎる・高すぎる字（frame のラベルは frame の幅に対して）。
- キャンバスからはみ出す部品（線・line・axis も）：0, 0 より左か上、または書いた `width`・`height` の外。
- 箱・印・ラベル・frame のラベルどうしの重なりと、frame の縁をまたぐ箱と印と、2 種類のラベル。場所を書いたラベル（`x`・`y` を書いたラベルと、`at` を書いた線のラベル）と、部品そのものが frame をまたげない部品のラベル（アイコンのラベルは手書きも `graph` も、棒のラベル）です。ラベルは、重なりと同じく、字の左右に 5 ずつの余白を含む箱で比べます（地の無いラベルも）。ほかのラベル（`at` の無い線のラベル（線の真ん中に立ち、線は frame をまたぎうる）、軸のラベル、`graph` の線のラベル、区域に置くラベル（`x`・`y` の無い `in`））は、frame の縁と比べません。誤りは越えた縁ごとに 1 つ出し、縁の場所と、その軸で部品が占める範囲を図の座標で言います（`at x 140, spanning 114.2 to 145.8`）。直すときは、部品の場所を決めるものを変えます。`x`・`y`、線のラベルの `at`、dot の `cx`・`cy`、棒の `x1`・`x2`・`y`（アイコンのラベルはアイコンと、棒のラベルは棒と一緒に動きます）、`graph` と `tree` が並べたものは全体の `x`・`y` です。frame の方を変えてもかまいません。frame どうしは比べないので、交わってよい。ただし、ほかの frame が交わる frame の縁をまたぐラベルや箱は、同じく断ります。
- 箱・ラベル・frame のラベルを通る線と、X の形に交わる線（片方に `crossing: true` があるか、どちらも 1 つの `graph` の線ならよい）。箱は描いた形で測るので、線は hex の尖りの外や丸い角の外を通ってよく、縁の上や縁から 1 以内を走ってもよい。同じ名前へ向かう、または同じ名前から出る手で書いた 2 本の線は、ラベルを分け合えます。片方の線が、もう片方のラベルの端から端まで同じ直線の上を走るときは、断りません。ラベルはどちらの線のものにも見えます（同じ名前から出た 2 本が、一度合わさって重なり、また分かれる形も通ります）。今までどおり断るのは、2 本が分け合う区間に 2 つのラベルがある形、ラベルの中で曲がる線、ラベルから 24（一番長い矢じり）より近くで終わる線、斜めの線、ラベルが自分の線の `via` の点の上にある形です。最後の形は、`via` で回っても直らないので、その点を外すかラベルを動かします。floe が動かしてラベルから離れた線があると、残った線が断られます。その線に `via` を書くと、動きません。
- どの部品も持たない名前や、端の部品に無い辺に着く線。

誤りの文は、部品を名前で名指します。名前が無ければ、幅を決めた言葉（一番広い言葉。同じ幅なら英語）の字を引用符で、字も無ければ置いた場所（左上と大きさ。`frame 10,10 250x150`）で名指します。線は、2 つの端を、部品と同じに名指し、座標の端は置いた場所で名指します（`edge "a"→"b"`、`edge "a"→[60,120]`）。`tree` の線は、2 つの節を、その箱と同じに名指します（`edge "a"→"B"`）。frame の角のアイコンは、その frame の `the icon of`（`the icon of frame "F"`）で名指します。`floe diagram inspect` も同じに名指し、名前の後に置いた場所を書きます（置いた場所で名指す部品では、1 回だけ書きます）。枠の見出しは、その枠の `the heading of` で名指し、図そのものは、一番広い言葉の題で名指します。
