# 図

`diagram` の部品は、節にも `details`・`tabs` の中にも置ける、その場に書く spec です。キャンバスと、その上に絶対座標（左上が 0, 0。どの座標も ± 100 万まで、大きさは 100 万まで、キャンバスは 1,000 万まで）で置く部品から成ります。ページを描く前に確かめ（誤りはデータファイルの行と列で言う）、拡大できる inline SVG で描きます。`floe diagram render` は、ファイルに書いた spec を同じように描きます（[commands.ja.md](commands.ja.md#floe-diagram-render-specyaml)）。

```yaml
- diagram:
    width: 640
    height: 200
    # スクリーンリーダーが読み上げる
    title: API の配置
    parts:
      - frame: { x: 16, y: 16, w: 608, h: 168, label: VPC }
      - box: { name: alb, x: 40, y: 72, w: 200, h: 56, tone: accent, rows: [[ALB, main code], 公開の入口] }
      - box: { name: api, x: 400, y: 72, w: 200, h: 56, rows: [API サーバー, ECS] }
      - edge: { from: alb, to: api, label: HTTPS }
```

- `width` と `height` は、それぞれ省けます。省くと、キャンバスは描いたものの右（下）の端まで広がり、さらに 20 空けます。左上は 0, 0 のままなので、座標は書いたとおりです。`raw` の SVG は測らないので、`raw` を使う図は `width` と `height` を書きます（書かないと切れることがあります）。
- ほかの鍵の代わりに `example: <種類>` を書くと、組み込みの見本を描きます（`floe diagram example` が並べる）。ページは図だけを見せ、spec は見せません。見本の spec を読む・写すときは、`floe diagram example <種類>` で出します。
- 文（`title`・行・ラベル）は、文か、言語ごとの言葉（英語を含む）です：`{ en: Store, ja: 保存先 }`。ページは `lang:` の言葉を描き、spec は書いた言語ごとに並べて確かめます。
- 図は、枠の中にページの地 `--bg` を塗ります。下の線を隠すもの（ラベルの下の四角、白抜きの端と点）も、その地で塗ります。白い面や、模様のあるテーマのページの上では、図はページの地の色の箱になります。
- 部品は、種類を名指す鍵 1 つで書きます。`floe part show diagram schema.json` がすべての鍵を出し、`floe diagram example <種類>` が種類ごとの spec を、格子を説明するコメント付きで出します。

| 部品 | 鍵 |
|---|---|
| `frame` | `x` `y` `w` `h`、`label`、`name`、`accent`、`square`（角を丸めない）、`icon`（`aws/group/region` のようなアイコン。AWS のグループの形で、角にアイコン）。ラベルは左上の内側に置くので、中身は上から 32 以上（アイコンがあれば 40）下に置く。 |
| `box` | `x` `y`、`rows`、`w` `h`（省けば行に要る大きさ）、`name`、`origin`（`left`。`x` を真ん中にするなら `centre`）、`tone`、`shape`（`rect`。`pill`、判断の `hex`、`state`）。行は文か `[文, 形]` で、形は `main`・`sub`・`main code`・`sub code`。形が無ければ最初の行が `main`、残りが `sub`。 |
| `table` | `x` `y`、`title`、`rows`、`w`、`name`、`origin`、`tone`。行は `[名前]`、`[名前, 型]`、区切りの `---`、または線が行に着く `{ name, cells: [名前, 型] }`。 |
| `icon` | `x` `y`（左上）、`icon`、`label`（アイコンの下）、`size`（48）、`name`。`icon` はセットとその中の名前で `aws/amazon-ec2` のように書く（`floe icons search` で探す）。 |
| `edge` | `from` と `to`（部品・名前付きの行・`tree` の節の `name`、または点 `[x, y]`）、`fromSide` と `toSide`（`top`・`right`・`bottom`・`left`）、`via`（曲がる点）、`straight`（直角でなく点から点へ）、`label` と `at: [x, y]`、`dashed`、`bold`、`tone`、`start`（`none`）、`end`（`arrow`）、`crossing`。端は `arrow`・`triangle`・`diamond`・`odiamond`・`one`・`many`・`zero-one`・`zero-many`・`none`。`crossing: true` でこの線はほかと交われる。 |
| `dot` | `cx` `cy`、`r`（7）、`name`、`tone`、`hollow`。線は中心まで届いてよい。 |
| `bar` | `x1` `x2` `y`、`name`、`tone`、`label`（棒の右）。 |
| `axis` | `x1` `x2` `y`、`ticks: [[x, 文], ...]`、`grid`（格子の線の上端）。 |
| `circle` | `cx` `cy` `r`、`name`、`tone`。円どうしは重なってよい。 |
| `label` | `text`、`x` `y`、`anchor`（`middle`。`start`・`end`）、`plain`（背景なし。`in` のあるラベルの既定。`false` で背景を付ける）、`strong`、`in`（ベン図で、内側に置く円の名前。ほかの円の外。`x` と `y` を省けば floe が置く）。 |
| `line` | `x1` `y1` `x2` `y2`、`kind`（`line`。`lifeline`・`divider`）。ほかの部品と交わってよいが、キャンバスから出ない。 |
| `tree` | `x` `y`（根の中心と上）、`root`：節。節は `box` と同じ `rows`・`name`・`tone`・`shape` と、子の節を並べた `children` を持つ。floe が各節を親の下に置き（子は横に並べ、深さごとに 1 段にそろえる）、親から子へ線を引く。節の `name` は、手で書いた線の端にできる。 |
| `graph` | `x` `y`（全体の左上）、`nodes`、`edges`、`direction`（`down`。`right`）、`nodes` の代わりの `lanes`。節は `box: { name, rows, tone, shape }`（`box` と同じ鍵を持ち、`name` は要る）か、`group: { name, label, accent, nodes }`（箱とまとまりを枠で囲むまとまり）。線は `{ from, to }`（その graph の箱かまとまりの名前 2 つ）で、`label`・`dashed`・`bold`・`tone`・`start`・`end`（`arrow` か `none`）を持てる。floe が箱を段に分けて並べ、箱の間に線を引く（下）。 |
| `raw` | `svg`：どの部品でも描けない SVG。SVG の要素だけで（script や `foreignObject` は無し）、配置も確かめもしない。 |

`graph` には、箱のつながりだけを書きます。置き場所は floe が決めます：

```yaml
- graph:
    x: 20
    y: 20
    nodes:
      - box: { name: write, rows: [Write the data] }
      - box: { name: check, shape: hex, rows: ["Checks pass?"] }
      - box: { name: show, rows: [Show the page] }
    edges:
      - { from: write, to: check }
      - { from: check, to: show, label: "yes" }
      - { from: check, to: write, label: "no" }
```

- 箱は、線が来る箱より下の段に置きます（輪を作る戻りの線も、書いた向きのまま描きます）。ただし、`level` と書いた線（下）の 2 つの箱は同じ段に立ちます。段の中の箱は、線の交わりが少ない順に並べ、交わりが無ければ書いた順のままです。同じ spec は、いつも同じに並びます。
- 線は、箱の辺の別々の点から、形の輪郭の上で出入りするので、2 本の線が同じ所を通りません。線の多い箱は広くなります（`right` では高くなります）。同じ graph の線どうしは交わってよく、graph の線とほかの部品は、ほかの線と同じく確かめます。
- 線の `label` は、graph の並び方を変えません。線を引いた後に、書いた from の箱に近い、線のまっすぐな区間の 1 列横の空き（縦の線は右、無ければ左。横の線は下、無ければ上）に、地の色なしで立ちます。空きが無ければ、floe がそこで図を広げて場所を作り（箱が広がることもあります）、線はラベルが無いときと同じにまっすぐです。ラベルの場所はいちばん広い言語の字で決めるので、どの言語でも同じに並びます。graph の `x`・`y` は、ラベルも含めた全体の左上です（1 列の内の差はあります。ラベルが箱より左や上に出ると、箱の格子を保つために、graph を 1 列の倍だけずらします）。
- `group` は、中の箱（入れ子のまとまりの箱も）を、どの段でも隣どうしに並べ、間にほかのものを入れません。floe はまわりに部品 `frame` と同じ枠を描き、`label` は枠の左上の見出し、`accent` は frame と同じです。枠はまとまりの箱とその間の線を囲み、ほかの箱を囲みません。中の箱と外の箱の間の線は枠の辺を横切り、まとまりの外の 2 つの箱の間の線も、まとまりの段の間で横切ることがあります。`label` が長いと、まとまりが広くなります（`right` では始まりの段が高くなります）。まとまりの `name` は枠の名前で、手で書いた線の端にできます。
- まとまりへの線は枠で終わります。上の段からなら枠の上の辺で、そうでなければ枠の下の辺から出ます（`right` では左と右の辺）。線ごとに別の点で、見出しを避けます。まとまりと、それが持つ箱・まとまりの間の線と、まとまりから自分への線は断ります。まとまりの箱の間の段にある箱（またはまとまり）からの線（まとまりの箱のどれかがそれと同じ段か上に、別の箱が同じ段か下に立つ）も断ります。まとまりの中の箱で終えてください。
- `nodes` の代わりに `lanes` を書くと、並べたものがそれぞれ帯（レーン）になります。帯は、まとまりと同じく `{ name, label, accent, nodes }` で書き、`group:` の鍵では包みません。帯は線の向きに graph の端から端まで（`down` では上から下まで、`right` では左から右まで）伸び、書いた順に 24 あけて並び、幅は中身の幅です。見出しの有る無しによらず、帯の上と下はそろいます。帯と、その中の入れ子のまとまりは、まとまりと同じです。ただし、帯は端にできません（帯の段の外から入る線は無いため）。帯の中の箱かまとまりで終えてください。
- `level: true` と書いた線は、2 つの箱を同じ段に立て、向かい合う辺の間をまっすぐ結びます（`right` では、上の箱の下の辺と下の箱の上の辺の間）。線は、段を横切る向きの辺が短い方の箱の、その辺の真ん中から半列ずれ、同じ 2 つの箱の間の線は 1 列ずつ離れます（短い方の箱は線の分だけ伸びます）。2 つの箱は、同じまとまりの中（どのまとまりにも入らない箱どうしも）か、別々の帯の直下に置きます。2 つの箱の左右（`right` では上下）は、段の中の並べ替えでなく、書いたものから決まります。同じまとまりの中で level の線でつながる箱は、書いた順に隣どうしに並び、別の帯への level の線を持つ帯の直下の箱は、その帯の側の帯の端に立ちます（両方の向きへ線を持つときは、帯の始まりの端）。そのため floe は、並べる前に次を断ります：まとまりを端にした level の線と、同じまとまりの中でも別々の帯の直下でもない 2 つの箱の間の level の線、level の線で同じ段に立つ 2 つの箱をつなぐ線、2 つの箱の間に何かが立つ線（同じ組で 2 つの間に書いた箱、帯の中で組の向く側に書いた箱、間の帯の箱か、その段にまたがる入れ子のまとまりの枠、どちらかの帯の同じ端に立つ別の組、始まりの端に立つ組の帯の、その段のほかのもの）、最初の箱の輪の辺を使う線。`right` では帯の見出しが最初の段に伸びるので、それを横切る level の線は、並べた後に断ります（見出しを短くしてください）。`level` と書いた輪は、ただの輪です（箱はもう 1 つの段にあります）。手で書いた線は、輪の辺と同じく、level の線の使う辺を避けます。
- 1 つの graph の箱とまとまりは、入れ子を数えて合わせて 200、線は 400 までです。図の全部の graph の線が端と端の間で越える段は、合わせて 4000 までです。
- `from` と `to` に同じ箱を書いた線は、その箱に戻る輪です。輪は graph の並び方を変えません。線を引いた後に、段をまたぐ graph の線が使わない辺（右の辺。`right` では下の辺。level の線はこの辺を使えません）から出て、書いた順に、最初のものを一番内にして入れ子に描き、ラベルは一番外の輪の 1 列外に順に並べます。箱は輪とそのラベルのために、その辺に沿って伸び、floe はラベルと同じく場所を作ります。
- graph の箱は、手で書いた線の端にもできます。その線は辺の真ん中で終わるので、graph の線が使わない辺を `fromSide`・`toSide` で選びます（graph の線の上を走らないように）。輪や level の線のある辺は、それらのものなので、手で書いた線の端にしないでください。
- graph の部品と手で書いた部品の間の誤り（重なり、線が箱を通る、交差）は、動かせる、手で書いた方の行と列に言います。graph の部品だけが起こす誤り（2 つの graph の重なりや交差、キャンバスからはみ出す graph）は、graph の場所に、その `x`・`y` を動かすよう言います（キャンバスからはみ出すときは、キャンバスを広げることも）。

`via` も辺も無い線は、相手に向いた辺から、直角に、曲がり 2 つまでで進みます。別の道にするには `via` か辺を書きます。

`via` を書いた線で、辺を書かない名前の端は、隣の via の点がその端の外の横にあれば左右、上下にあれば上下の辺を使います（`straight` の線も）。点が斜めにあれば、直角の線の終わりの端は、線が来た向きの辺を使います。始まりの端と `straight` の線で点が斜めのときと、点が端の中や縁の上にあるときは、`via` の無いときと同じく相手の端に向いた辺を使います。表の行はいつも左右の辺で、dot は辺を持ちません。辺を書いた端は書いた辺を使います。直角の線の終わりの辺には、書いた辺でも選んだ辺でも、via の点がその辺の外側にあれば最後の区間が直角に入り、曲がり 1 つでは来た線を戻るときは、間の真ん中で 2 回曲がります。via の点が書いた辺の外側に無いときは、前の区間の向きのまま入り、端の縁を這うことがあるので、via は辺の外側に書きます。

確かめること：

- 箱に対して広すぎる・高すぎる字（frame のラベルは frame の幅に対して）。
- キャンバスからはみ出す部品（線・line・axis も）：0, 0 より左か上、または書いた `width`・`height` の外。
- 箱・印・ラベル・frame のラベルどうしの重なりと、frame の縁をまたぐ箱と印。frame どうしは比べないので、交わってよい。
- 箱・ラベル・frame のラベルを通る線と、X の形に交わる線（片方に `crossing: true` があるか、どちらも 1 つの `graph` の線ならよい）。箱は描いた形で測るので、線は hex の尖りの外や丸い角の外を通ってよく、縁の上や縁から 1 以内を走ってもよい。
- どの部品も持たない名前や、端の部品に無い辺に着く線。
