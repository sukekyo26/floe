floe の主要な変更を記録します。フォーマットは

## [Unreleased]

### 追加

- 追加：テーマ `cyber`。ガンメタルの地の、夜の街の端末。箱は上の辺の虹と 2 つの切り落とした角のホログラム、節の見出しに `//01` とバーコード、表は端末の帯の頭、注意は tone ごとに形の違う枠。
- 追加：`floe repository new`・`render`・`check`・`template`・`part`・`theme`。設定を付けずにリポジトリの文書を扱います。`.floe/repository.yaml` に floe の版と文書のディレクトリを書き、`floe repository check` の 1 行で、`.floe/` のテンプレート・部品・テーマと、全部の文書とそのページを、リポジトリのどのディレクトリからでも、CI でも確かめます。`FLOE_TEMPLATES_DIR`・`FLOE_PARTS_DIR`・`FLOE_THEMES_DIR` は読まず、サーバーを使わず、設定と別の版の floe は断り、アイコン集のほかは、リポジトリの外を読みも書きもしません。
- 追加：`page.html` と `part.html` の関数 `count`。`{{count $i}}` は `range` の添字を 1 から数えた数を書くので、テンプレートが項目の番号を CSS の counter でなくページの文の中に書けます。

### 変更

- **BREAKING**: 変更：floe のテンプレート `design` の名前を `tech-spec` に変えた（ページは前のまま）。`template: design` のデータは知らないテンプレートとして断られ（`unknown template "design"; use adr, handoff, postmortem, report, runbook, slides, tech-spec`）、`floe rebuild` は保存したページについてそう言い、前に描いたまま残す。そのデータの `template:` を `tech-spec` に書き換えて publish し直す。`--from design` で作った自分のテンプレートは変わらない。`design` の名前は、これから足す画面のデザインのテンプレートに使う。
- 変更：部品 `links` が、1 つのリンクを 1 行の小さな枠（札）にして横に並べるようになった。札の頭に行き先（floe の中のパスは `docs`、github.com の PR は `PR #412`、メールは「メール」、ほかはホスト名）、題の後ろに floe の外へ出るものは ↗ を出し、`text` は札の横に添える。行と鎖の印、囲みの枠、題の下の URL は無くなり、印刷したページでは行き先だけが分かる。データはそのまま描ける。`part.html` に、URL の行き先を出す関数 `linkTo` を足した（`links` から作った自分の部品も使える）。
- 変更：Markdown（部品 `text`、Markdown の欄、部品の中の Markdown）の見出しを、どのテンプレートの見出しより小さくした。`#` は 1.05em、`##` は 1em、`###`〜`######` は 0.95em。`adr`・`postmortem`・`runbook` で `#` が節の見出しより目立たず、`##` が `adr` の節の見出しと同じに見えない。
- 変更：`slides` が、各枚の番号と枚数をページの文として書くようになった。選んで写せ、読み上げで読まれる（「スライド 2、全 5」）。見た目は変わらない。
- 変更：`floe task` がタスクを作るのは `--new` を付けたときだけになった。`--new` を付けないと作らなくなった（前は、無いタスクに `--state`・`--title`・`--url`・`--parent`・`--categories` を書くか、`--slug` でページを載せると、黙って作った）。そうした書き込みは、今は断る（`no task S9 in project app: check the ID, name its project with --project, or make it with --new`）。ID やプロジェクトの誤りで空のタスクを作らないため。先に `floe task --task <ID> --new` で作り、後からページを載せる。既にあるタスクの `--new` は断る。
- 変更：テーマ `aurora` の注意（note）の白い外枠を外し、ほかのガラスの箱と同じ影だけで浮かせた。どの tone の地も一段濃くし、色の無い（accent の）注意がページの紫のにじみに溶けないようにした。
- 変更：テーマ `app` の注意の印を小さくし、1 行の注意が字の行と余白の高さに収まるようにした。
- 変更：部品 `note` が、どのテンプレートでも、本文やほかの部品と同じく置いた所の幅いっぱいになった。これまでは `--text-width`（56rem）で止まり、広い画面やスライドで短く見えた。
- 変更：テーマ `retro` を、70 年代から 90 年代のパソコンの画面にし、ほかのテーマに無い色にした。明るい灰の地に浮いた縁の白い箱、札・番号・表の頭は灰のボタン、節ごとに閉じる箱の付いた紺から青の題の帯（帯の見た目も同じ紺から青）、目次の今の節を選択の面にする青緑の差し色、tone の色の四角い浮いた札の注意の印、ブロックで満たす進みの棒、+ と − の箱の畳み、灰の頭の窓の code。角は四角
- 変更：テーマ `default` の注意と折りたたみを変えた。注意は、題と本文と印をその色の淡いタイルに載せ、周りにその色の濃いめの細い縁を残し、印は白い四角からその色で塗った丸にした。開いた折りたたみは、灰のトレイの中で中身が白いタイルに載る。

- 変更：テーマ `aurora` の色を、記事の字の邪魔にならない強さにした。地のにじみは桃と薄荷を抜いた紫の濃淡だけ、節の線（3px に）・表の頭の下の線・勧めの案の上の縁は紫から藤桃への光の線、差し色の札はどこでも紫の塗りに白い字、ガラスの箱と引用は細い紫の枠で囲んで箱の中の箱（手順の中の表など）をまわりのガラスと分け、`design` の節の見出しの左の線は淡い紫、ページの頭の下の線は 3px。

- 変更：テーマ `soft` を、ほかのテーマに無い桃と葡萄の色にした。淡い桃の地に枠の無い面が浮き、節は丸い桃の帯から始まり、表の頭は丸い帯で縞の行は淡い桃で両端が丸く、注意は角 26px と大きな印（tone の無い注意は藤鼠）、数の題と決定の状態・日付は丸い桃の札、数は葡萄色の大きな字。

- 変更：テーマ `editorial` を、ほかのテーマに無い墨と黄の色にした。節の頭は黄の帯に墨の札の番号、カード・数・勧めの案の上には字の始まりに短い黄の罫、表は上に太い墨の罫、注意は左に太いその色の縁、決定は上に太い黄の帯と大きな題、数は大きく太い字。差し色は墨なので、テンプレートが差し色で塗る帯は黒く、tone の無い注意は墨の灰の面になる。

- 変更：テーマ `app` の部品を、白いカードのまま、アプリの部品の形にした。注意はその色がごく淡い面に大きな角丸の四角いアイコンの付いた通知、決定はつまみのある下から出たシート、折りたたみは右の端に矢印のある設定の行、引用は吹き出し、表の暗い頭はカードの中の角の丸い帯。数は本文の字体で描き、節の見出しの下に短いラズベリーの棒を置き、文中のコードの面を灰にし、英字は `default` と同じく日本語の字体で描く（Windows では Segoe UI が英字を横長に描いていた）。

- 変更：`floe part new`・`theme new`・`template new`（`floe repository` のものも）が、`made <パス>` の次の行に、読む手引きと元にする floe のファイルを出すコマンドを言う（`next: read floe theme guide; floe theme show default palette.css prints floe's own to start from`）。

### 修正

- 修正：テーマ `default` で、テンプレート `adr` が灰色の紙 1 枚に見え、節の境目が分かりにくかった。`default` の台（panel）の灰色を薄くし（`default` で描くページ全部。`runbook`・`handoff` の台、部品 `panel`、カードなど）、`adr` では決めたことと選ばなかった案を白い面（surface）の升に、結果の 2 つを tone の薄い色の囲みに載せる（どのテーマでも）。
- 修正：管理ページの検索とページを追加のモーダルの行で、題の下の段が収まらないと、長いプロジェクトや載っているタスクの印が行とモーダルの外まで伸び、リンクのパスが潰れて見えなかった。一覧の行と同じく次の段に折り返し、段より広い印は末尾を「…」で切り、パスの幅を残す。
- 修正：管理ページの行の題の下の段で、タグ・プロジェクト・タスク・種類の印の名前が長いと、印が段より広くなり、行のボタンの下や行の外まで伸びていた（タスクの印は広い画面でも）。段の幅で末尾を「…」と切って収める。
- 修正：管理ページのタスクのページで、プロジェクトの名前が長いと、頭が列より広くなり、「編集」や親子のカードの「追加」が窓の外に出ていた。プロジェクトの印を末尾で「…」と切って収める。
- 修正：管理ページのフォルダのツリー（一覧とタスクのページ）で、列が狭く階層が深いと、ページの名前が日時とボタンに幅を取られて消えていた。名前におよそ 10 字の幅を残し、横に入らない行だけ、日時とボタンを名前の下の行の右に回す。入る行は今までどおり 1 行。
- 修正：管理ページの帯の floe のアイコン・「ページ一覧」・「タスク一覧」を押しても、畳んだ棚と一覧の列が畳んだままだった。ふつうに押すと、移った先の画面（今いる画面でも）で両方を開き、読み直しても開いたままにする。
- 修正：サーバーを使うコマンドが、答えないほかのプログラムが持つポートを断るまで約 20 秒待っていた。答えずにつなぎを切るもの（エディタのポートの転送など）は、すぐ別のプログラムとして断り、つないだまま黙るものは 10 秒の待ちを 2 回でなく 1 回で断る。待つ間にポートが空けば、すぐ取る。

## [0.4.0] - 2026-11-26

### 追加

- 追加：管理ページのタスクの「編集」で、タスクの ID を変えられる。変えると、タスクのページ（アーカイブしたものも）と子のタスクの親も同じ書き込みで新しい ID に移り、画面は新しい ID のタスクのページに移る。プロジェクトのほかのタスクの ID には変えられない。古い ID はどのタスクも指さなくなる。
- 追加：テーマ `pebble`。暖かみのある背景に、行がトレーに並ぶ丸い石になり、部品ごとに形が違う。差し色は茶色で、セクションの見出しは端から端までの帯。
- 追加：テンプレート `report` と `design` のセクションの見出しのうち、`page.css` だけが決めていた所を、自分のテーマが `base.css` の `:scope` に書く変数で変えられる。`report` は上の余白（`--floe-heading-top`）、`design` は左の余白と左の線（`--floe-heading-start`・`--floe-heading-edge`）。変数を書かないテーマの見た目は変わらない。
- 追加：タスクのページの「ページを追加」のモーダルで、新しいカテゴリを足せる。プルダウンの横の「カテゴリを追加」で名前を打ち、ページを付けたときに作られる（付けずに閉じると作られない）。もうある名前の断りの字は、「編集」でも「「設計」というカテゴリはもうあります」になった。
- 追加：図の `tree` が、`direction: right` で右へ、`left` も書くと根から左右へ（マインドマップのように）広がる。節の場所はどれも floe が決める。見本は `floe diagram example mindmap`。下向きの木の書き方と絵は変わらない。
- 追加：`floe repository guide` を足した。リポジトリに置く文書（データファイルと描いたページ）の直し方と、CI で確かめるリポジトリの組み立て方を出す。`floe guide` は、そのような文書のときにこれを指す。

### 変更

- 変更：checkout からビルドした floe（`go build`・`go install ./cmd/floe`・`just build`）の `floe --version` と `floe version` が、ビルドした commit を `+` の後に添える（`0.3.1+09feb55824ca`。作業ツリーに変更があれば `.dirty` も）。リリースの floe とこれで見分けられる。リリースは今までどおり版だけを言う。
- 変更：テーマ `swiss` の箱の境が見えるようにした。注意・カード・案・折りたたみなどの箱が、表と同じく、どこに置いても黒い枠の中の白い面になる（前は面が無く、上か左の線だけだった）。引用は白い面、図は灰の面に立ち、注意（warn）の灰は濃く、ページの地もわずかに濃くなる。
- 変更：`checks.yaml` の `for` がリストに着かない誤りを、パスが止まったデータの値ごとに、その行と列に出し、`for` と `checks.yaml` を名指すようにした。前は、検査ごとに 1 つを `for` の場所に出していた。
- 変更：上の帯の「ページ一覧」「タスク一覧」が、開いている方が灰色の溝の中の白いつまみに乗る切り替えスイッチになった。全面で開いたページでは、開いた元の一覧が乗る。幅 56rem（これまで 40rem）以下の全面のページでは、代わりに戻るリンクの印が出る。リンクであることと、行き先は変わらない。
- 変更：管理ページの長い一覧が、早く出るようにした（300 ページで、行が見えるまで約 80 ms 短い）。全面で開いたページも少し早い。「…」の項目は開いたときに作るので、ブラウザのページ内検索は、閉じた「…」の字を見つけない。
- 変更：管理ページのタスクのページの並び。タスク一覧へ戻るリンク（0.3.0 で外した）を、題の左の「‹」の印で戻した。行き先は上の帯の「タスク一覧」と `h` と同じ。「編集」は題の右、完了したタスクをアーカイブするボタンは状態の横になった。「ページを追加」は、アーカイブしていないページの数を丸い印で出す見出し（「ページ 2」）の横の「追加」になった。子のタスクの見出しの数も、同じ印になった。
- 変更：`floe publish` が、0.1.0 より前に保存したページ（どのファイルのページかを持たない）を、`--force` 無しでは、元のファイルからでも断る。前は、同じプロジェクトの別のファイルや、プロジェクトの無いページならどのファイルでも、断らずに書き換えた。`--force` では、ほかのファイルのページと同じく置き換え、版・タグ・お気に入り・タスクを捨てる（前は、そのようなファイルからは残した）。
- **BREAKING**: 変更：`floe template check`・`floe part check` が、`checks.yaml` の `for` の道が、`type` が鍵と値も並びも許さない値（`"type": "string"` や、その並びの項目）の先へ続くとき、断るようにした。検査は項目を 1 つも見つけずに黙って通るか、データを断っていた。道を直すか、検査を消す。それまでは、自分のテンプレートや部品のほかの誤りと同じく、どのページも止まる。
- 変更：`floe skill install` のスキルが、リポジトリの文書を書く・直すときにも使われる文になった。前からの利用者は `floe skill install <agent> --force` で入れ替える。

### 修正

- 修正：管理ページのタスクのページで、タイトルが折り返すと 2 行目がタスクの ID の下から始まっていた。ID を 1 行目に置き、タイトルは次の行から、各行の頭を揃えて始まる。
- 修正：管理ページの星（押した星・指した星、棚の「お気に入り」、検索と「ページを追加」の行の星）が地に溶けて見えにくかったので、濃い金にした。どの地とも 3:1 以上のコントラストになる。
- 修正：「ページを追加」で Enter を押したままにすると、断りの後に、読む前にもう 1 度送られた。
- 修正：管理ページのモーダルを開く・閉じる押下やキーの続き（二度押しの 2 回目、押しっぱなしのキー）が、開いたモーダルの中や背景、閉じたモーダルの下の行やボタンに届いた。「ページを追加」で、ほかのタスクのページの行を二度押しすると、問いを読まないまま移ることがあった。
- 修正：全面で開いたページの帯が、日本語で、アーカイブ済みで版が 2 つ以上のページのとき、幅 640〜650px ほどの窓で横にはみ出していた。
- 修正：タスクの題に、折り返す所の無い長い並びがあると、タスクのページが横にスクロールしていた。題が折り返すようにした。

## [0.3.0] - 2026-11-24

### 追加

- 追加：`floe licenses` が、管理ページの作りに入ったライブラリ（React などのパッケージと Tailwind CSS）の許諾も出す。
- 追加：`install.sh` と `install.ps1` に `FLOE_INSTALL_TIMEOUT`。何も届かない状態を、1 回のリクエストごとに何秒まで待つかを指定する（既定は 120）。

### 変更

- 変更：管理ページ（ページ一覧 `/`、タスク一覧とタスクのページ `/tasks`、全面で開いたページ `/a/<slug>/`）を、作り直した画面にした。できることは同じ。見た目と動きの違い：
  - どの画面も：上の帯の「ページ一覧」「タスク一覧」が、開いている画面の方を枠で囲む切り替えから、字だけの 2 つのリンクになり、開いている画面の方が濃くなった。サーバーにつながらない時の印が、帯でロゴから少し離れた。画面を描けない時の文が「画面の表示に失敗しました（…）」になった。スクリーンリーダーが、ページの「…」の「選択」「パスをコピー」をページの題と一緒に読み、横にページを開いている行を「現在の項目」と読む（`aria-current`）。タグのモーダルで、ほかのタグの頭と同じ名前（`Foobar` がある時の `Foo`）を打って Enter を押すと、そのタグに印が付く（今までは何も起きなかった）。開いてすぐ読み直すページでも、既読のトーストと新しい版の知らせが出る。ヘルプの 2 つの切り替え（この画面について・キーボードショートカット）が、黒い地のボタンから、開いている方に線の付くタブになり、← → で移れる。
  - ページ一覧：選んだページの帯の最後の × が、字の「解除」になった。「指定した版を開けない」の文は、そのページの名前を変えると消える。一覧の行にフォーカスがある時に開いた探すから「編集」を開いて保存した後、フォーカスがその行に戻る。

- 変更：置き場所が `PATH` に無いときに `install.sh` が言うこと。足すコマンドを、写して貼ればそのまま動く形で見せる（zsh は `~/.zshrc`、Linux の bash は `~/.bashrc`、fish は `fish_add_path`。sh の仲間のほかのシェルには足す行だけ）。`PATH` もファイルも、今までどおり変えない。相対パスで渡した置き場所は絶対パスで言い、絶対パスで比べるので、もう `PATH` にある置き場所を案内しなくなった。
- 変更：`floe guide` が、場所の無い断りのうちコマンドに渡したもの（パス・フラグ・URL 名・タスク・自分で置いた `FLOE_…`）についてのものはエージェントが直し、ほかはユーザーに伝え、ユーザーの設定を変えずサーバーを止めない、と言うようにした。前は場所の無い断りを全部、ユーザーに伝える故障と言っていた。

### 修正

- 修正：ページの URL 名の変更でページを動かせなかったとき、説明・タグ・プロジェクト・題だけが保存され、ほかは失われていた。ページを先に動かし、動かせなければ何も保存しないようにした。動かした後に `meta.json` を書けなければ元に戻し、戻せないときは、URL 名だけが変わり、ほかの変更はもう一度保存すると言う誤りで断る。
- 修正：1 MiB を超えたログを `server.log.1` へ動かせないとき（そこにディレクトリがある、前のサーバーが開いたまま）、サーバーが起動しなかった。今のログへ書き続け、動かせなかった理由を 1 行書き、次の起動でまた試すようにした。

## [0.1.1] - 2026-11-16

### 変更

- **BREAKING**: 変更：`floe task --categories` を、`--url` と同じくカテゴリ 1 つごとに繰り返す旗にした（`--categories designs --categories samples`）。名にカンマを使える。`--categories ""` で全部外すのは今のまま。`floe task` はカテゴリを URL と同じく 1 つずつ引用して出す：`categories "a,b"` でなく `categories "a" "b"`、書き込みで最後の 1 つを外した後は `categories ""` でなく `no categories`。ページのあるカテゴリの断りは名を引用符で囲む（`category "designs" of task …`）。その行と `floe info` の値（題・タスク・カテゴリ・タグなど）は、全角空白を `\u3000` でなくそのまま出す。
- 変更：`floe guide` のタスクモードの問い。エージェントは新しいページを publish するたびに、どのタスク（開いたタスクの先頭 2 件・新しいタスク・無し）に置くかと、そのタスクのどのカテゴリに置くかを、質問ダイアログで（無ければ問いだけの返事で）ユーザーに聞く。
- 変更：`floe task` とタスク一覧の並び。状態だけでなく、欄を変えたときや、ページを載せたか、そのタスクの別のカテゴリへ移したときも数え、最後に変えたタスクを先に並べる。タスクに出る時刻もその変更の時刻。ページだけを書いた `floe task --slug … --task …` も、そのタスクを `changed` の行で言う。

### 修正

- 修正：プロジェクトの無いタスクの断りが `project /` と言っていた。`floe task` と管理ページは、`no project`（日本語は、タスク一覧の「未設定」に合わせて `プロジェクト未設定`）と言う。管理ページの日本語の断りでは、名のあるプロジェクトも `プロジェクト「floe」` と囲む。無いタスクを `--parent` で名指したときは `no task #42 in project app can be a parent` と言う。
- 修正：`floe publish` に `--link` と `--move-project` を一緒に渡したときの断りに `run floe --help` が付かず、終了コードが 1 だった。ほかのコマンド行の誤りと同じく、断りの末尾に `run floe --help` を付け、終了コードを 2 にした。

## [0.1.0] - 2026-11-16

### 追加

- 追加：`floe publish`。データファイル（YAML）からテンプレートでページを描き、ローカルのサーバー（`http://127.0.0.1:7325`、動いていなければ起動する）で見せる。`--link` は自分の HTML のファイルやフォルダをそのまま見せる。
- 追加：データファイルを確かめる `floe check`、リポジトリに置くページを書く `floe render`、保存したページを扱う `floe list`・`floe info`・`floe tag`・`floe archive`・`floe rm`・`floe rebuild`・`floe serve`・`floe stop`。
- 追加：誤りを、誤った所のファイル・行・列で、直し方と一緒に言う。より良い書き方を勧める警告。
- 追加：floe のテンプレート `report`・`design`・`handoff`・`adr`・`postmortem`・`runbook`・`slides` と、自分のテンプレート（`floe template new`）。
- 追加：floe の部品（text・code・terminal・diff・table・entries・steps・stats・bars・chart・checks・asks・options・columns・image など）と、自分の部品（`floe part new`）。
- 追加：12 のテーマと、自分のテーマ（`floe theme new`）。既定のテーマとページのテーマは、人が管理ページで選ぶ。
- 追加：検査付きの inline SVG の図。枠・箱・線・表・木、線から並べる `graph`、見本（`floe diagram example`）。
- 追加：図のアイコン。Lucide を組み込み、AWS・Google Cloud・Azure のアイコン集を `floe icons fetch` で取り、`floe icons search` で探す。
- 追加：管理ページ。プロジェクトごとのページ、検索（`Ctrl+K`）、タグ、ピン、アーカイブ、ページの版と版の違い、未読、設定。
- 追加：プロジェクト。ページを初めて publish した git リポジトリの名前で決まる（`--move-project` で移す）。
- 追加：タスク。プロジェクトと状態ごとのタスク一覧、子のタスク、並べられる外のリンク、タスクの中のページのカテゴリ。`floe task` で読み書きする。
- 追加：タスクモード。入なら `floe guide` が、新しいページを publish した後に、タスクに載せるかをユーザーに聞くようエージェントに言う。
- 追加：エージェントの手引き `floe guide` と、`floe task guide`・`floe diagram guide`・`floe part guide`・`floe template guide`・`floe theme guide`、エージェントのスキルからそれを指す `floe skill install`。
- 追加：ページの CSP とサンドボックス。ページの script を floe のものだけにする。
- 追加：`floe licenses`。floe と、floe に入っているもののライセンスを出す。
