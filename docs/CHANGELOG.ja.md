## [Unreleased]

### 追加

- 追加：テンプレートがページを中央にそろえる列を、class `floe-column` の要素に置けるようにした。幅は `--column-width`
  （テンプレートが置かなければパレットの `--page-width`）で、左右に `--page-pad` をあけ、テンプレートの `page.css` が勝つ。
  1 列のページは `:scope { --column-width: var(--text-width); }` を置く。floe のテンプレートは、列を自分で書く代わりにこれを使う。
- 追加：テーマの `markdown.css`。ページの上、text の中、部品の中の、どこにある Markdown にも
  当たる Markdown の見た目（引用、見出し）。floe のテーマは引用（retro は見出しの縞も）をここで
  描く。部品・見た目の名前に `markdown` は使えない。
- 追加：図の部品 `graph`。箱と、それをつなぐ線を名前で書くと、floe が段に並べ
  （`direction: down`・`right`）、段の中を線の交わりが少ない順に並べ、線を箱の辺の
  別々の点の間に直角に引く。線はできるだけまっすぐに引き、線の入る場所が 1 列足りない箱は
  横の空いた所へ広がり、段を越える線は、自分の列を離れる所で 1 回だけ曲がる。線の `label` は線のまっすぐな区間の横に立ち、空きが無ければ
  floe が線を曲げずに場所を作る。箱から同じ箱へ戻る線は、graph の線が使わない辺に出る
  輪になる。節の `group`（まとまり。入れ子にできる）は、中の箱をどの段でも隣に並べ、
  `label` を見出しにした `frame` の枠で囲み、線はまとまりも端にでき、枠の上か下の辺で終わる。
  `nodes` の代わりに `lanes` に書いたまとまりは帯（レーン）になり、graph の端から端まで、書いた順に、上と下を
  そろえて並ぶ。`level: true` と書いた線は、2 つの箱を同じ段に立て、向かい合う辺の間を
  まっすぐ結ぶ。2 つの箱は、同じまとまりの中で書いた順に隣に並ぶか、別々の帯の直下で、
  それぞれ相手の側の帯の端に立つ。2 つの箱の間に何かが立つ線と、箱の輪の辺を使う線は断る。
  1 つの graph は箱とまとまり 200・線 400 まで、図の全部の graph の線が端と端の間で越える段は
  合わせて 4000 まで。図の見本 `flow`・`state`・`swimlane` はこれで描く。
- 追加：部品と見た目の `part.yaml` の `marks:`。どの要素が左に印のある行かを、`box`・
  `items`（子の `li`）・`joined`（次への線つき）で言う。floe が行を層 `floe.marks` に
  1 つ並べ（印の置き場所と大きさ）、印は部品が描く。部品の見た目の連なりで `marks:` を
  2 回書くと、`floe part check` が断る。
- 追加：見た目 `marked`。並びの項目の前の字を行の印にする。decision・options・checklist・
  handoff の済んだ作業が借りる。
- 追加：見た目 `numbered` の項目の `data-floe-mark`。`ring` は縁を tone に、`solid` は丸と
  線を tone で塗る。
- 追加：パレットの `--quiet`（箱の中の静かな地）。表の頭、棒の溝、progress の地、キーが
  読む。
- 追加：パレットの角の丸さの変数 `--radius`・`--radius-small`・`--radius-pill`（どれも
  1 つの長さ）。箱、箱の中の小さな升、札の丸さ。部品・テンプレート・floe の base・テーマが
  読み、テーマは丸さをパレットだけで決める。
- 追加：静かな tone `muted`（`--muted-soft` の地に `--muted` の色）。tone を書ける
  所（note、pill、表の pills、bars、progress、stats、timeline、図）のどこでも書ける。
  adr の deprecated・superseded、postmortem の重さ low、fields の型はこの色で描く。
- 追加：`--tone-fill`。テーマが tone を塗る色で、パレットの `--<tone>-fill`
  （`--good-fill`）から、無ければその tone の `-soft` から。
- 追加：図の `width` と `height` を省けるようにした。省くと、キャンバスは描いた
  ものの右（下）の端まで広がり、さらに 20 空ける。左上は 0, 0 のまま。`raw` の
  SVG は測らないので、`raw` を使う図は両方を書く。
- 追加：行の形のもの（見た目 table と rows、それを借りる部品、テンプレートの表と
  一覧、facts のタイル）の、行の上下の余白を 1 つにそろえた。0.4rem で、floe の
  base.css の `--floe-row-pad` が決め、行の高さはページのもの。自分の部品は、見た目
  rows を借りるか、変数を読んでそろえる。
- 追加：YAML のファイルの値についての誤りの行と列を、その値の最初の字の所で言う。floe の
  YAML のライブラリは、タブの後、行の終わりに空白がある値、CRLF の行のコメントや改行を
  またぐ引用符の後で、位置をずらして返す。
- 追加：表の列を題の字だけで書けるようにした（`columns: [リスク, 担当]`）。
  題のほかに何かを持つ列だけ、オブジェクト `{ title, num, pills }` で書く。
  列の `pills` は言葉とその色（`{ 済: good, 未: bad }`）で、その列の升が言葉と
  丸ごと同じなら、升ごとに `{ pill, tone }` を書かずに、その pill で描く。
- 追加：部品の `part.html` の関数 `written`。部品の値を書いたまま（中の部品と
  format を描く前）で返し、升の字を言葉と比べるのに使う（floe の `table` は列の
  `pills` をこれで比べる）。
- 追加：部品 `entries`。記録を縦に並べ、1 つが見出しとその横の札（表のセルと同じく
  Markdown の 1 行か pill）、その下の全部の幅の Markdown の文。名前と、それより長い文
  （要件、リスクとその手当て、用語）のためのもので、状態は札に書く。
  部品を置ける所と、`details`・`tabs` の中に置ける。
- 追加：字下げの数を書かない `|` や `>` の文で、空白だけでない最初の行が空白の後にタブで始まる
  （タブだけの行も）ものを断る。floe の YAML のライブラリはそのタブを字下げに数え、後の行を
  落としたり短くしたりする。
- 追加：管理ページでページの枠を印刷すると、iframe が印刷する 1 画面分の代わりに、ページだけを開いて
  印刷するよう言う言葉と、その URL を出す。
- 追加：印刷でも、ページの地を含めてどの地も画面のとおりに出す（塗った地の上の明るい字が白い紙に消えない）。
  CSS の変数 `--face`・`--on-face`。色で自分を塗る面（帯、swiss の危険の注意と灰色の注意、ink の引用、
  コード）が地と字の色を置くと、floe の土台が中のリンク・行の code・フォーカスの輪をその字の色で描く。
- 追加：`floe theme list` と `floe theme show`。`floe part show`・`floe template show`・
  `floe theme show` は、部品・見た目・共有の schema・テンプレート・テーマが読むファイルを全部、
  並べた `files:` の行の後に、1 つずつ `==> 名前 <==` の下に書いたとおりに出す。ファイル名を足すと、
  そのファイルだけを、先頭の BOM を除いて書いたとおりに出す（`floe part show code part.html`）。
- 追加：floe のテンプレート `slides`。1 枚ずつ見せるスライドで、帯の表紙の後に、画面の高さの枚
  （見出しと report と同じ部品）を並べ、スクロールで 1 枚ずつ止めて右下に何枚目かを出す。見出しだけの枚は
  話の区切りになり、印刷すると 1 枚が 1 ページになる。`direction: across` と書くと枚を横に並べ、← → のキーや
  左右のなぞりで送る。
- 追加：floe の見た目 `numbered`。リストの項目に丸い番号を付け、次の項目へ線でつなぐ。部品 `steps`
  が借り、テンプレートは `<ol>` に `data-floe-look="numbered"` で借りる（runbook の手順もこれを借りる）。
- 追加：floe のテンプレート `runbook`。打つコマンドと一緒に残す手順書で、始める前に確かめること、
  注意、番号と線でつないだ手順（行う人の札、写すボタン付きのコマンド、失敗したらすること）、
  別の枠の戻し方を並べる。
- 追加：floe のテンプレート `postmortem`。人を責めずに書く障害の振り返りで、帯の中の要約と
  重さの札（重大・中程度・軽微。赤は重大だけ）、影響、部品 `timeline` で描く時系列、原因、
  うまくいったこと・まずかったこと・運が良かったこと、担当と状態（これから・作業中・済み）の
  付いた対策を並べる。
- 追加：floe の見た目 `band`。アクセントの色で塗った帯で、中の字・リンク・code・フォーカスの輪を、
  塗った面の上の字の色にする。テンプレートは `data-floe-look="band"` で借りる（design の結論と
  handoff・postmortem の頭もこれを借りる）。
- 追加：floe のテンプレート `adr`。1 つの決めたことを紙 1 枚に書く記録で、題の下に状態の判子
  （提案・採用・却下・廃止・置き換え済み。置き換え済みなら置き換えた記録を書く）、背景、決めたこと、
  選ばなかった案と理由、良くなることと引き受けることを並べる。
- 追加：floe のテンプレート `handoff`。決めてほしいことを先に出す、作業の引き継ぎと状況の
  知らせで、日付、渡す人と受け取る人、終えた・進行中・決めてほしい・次にやるの数、Q1・Q2 と
  番号の付いた問いと案と勧め、誰が何をしていて答え待ちか止まっているか、次にやること、気を付けることを書く。
- 追加：floe のテンプレート `design`。結論を先に出す設計書で、必須の背景と目的に、
  やらないこと、判断（問いと部品 `options` の案。`pick` を付けた案がページの一番上に出て、
  無いものは未決と出る）、案を比べずに決めたこと、影響の範囲、見出しと部品の自分の節を続ける。
  判断の問いは、案の上の見出し。
- 追加：`code`・`terminal`・`diff` の右上に、中身を写すボタン。code は書いたまま、
  terminal はプロンプトと出力を除いたコマンドだけ、diff は書いたままを写し、
  写したことをページの言語で示す。ページがクリップボードに書けない所（VS Code の
  Simple Browser など）でも写す。長い行は、右端までスクロールすると、終わりがボタンの
  左に出る。
- 追加：警告。ページのより良い書き方の勧めで、`floe check`・`floe render`・
  `floe template check`・`floe publish` が、誤りの後に
  `file:line:column: warning: message` で出す。ページは描き、終了コードも
  変えない。最初の警告は、`text` の部品（report の節と、design・handoff・adr・
  postmortem・runbook の `more` の中、runbook の手順の `text`、slides の枚、
  `details`・`tabs` の中も）の囲んだコードのブロックで、ただのコードとして描き、`code` か `terminal` に
  書くよう勧める。`text` は部品の 1 つになったので、自分の部品に `text` という
  名前があると断る。
- 追加：図の部品 `tree`。木の節と子だけを書けば、floe が各節を親の下に置き、
  線を引く。あわせて図の例 `org`（`floe diagram example org`）。ある会社の
  部署を `tree` で描く。
- 追加：図の例 `gantt`（`floe diagram example gantt`）。作業の期間を棒で、
  待つつながりを矢印で描く図で、あるアプリの 1 つの版の 6 週間の予定を置く。
- 追加：図の例 `quadrant`（`floe diagram example quadrant`）。2 つの軸で項目を
  4 つの領域に分ける図で、ノートのアプリの機能の候補を、価値と手間で置く。
- 追加：図の例 `swimlane`（`floe diagram example swimlane`）。流れを、する人ごとの
  レーンに分けた図で、ユーザー・アーキテクト・エンジニアの 1 つの PR の流れを描く。
- 追加：アーカイブ。`floe archive <slug>...`（`--undo` で戻す）、管理ページの
  「アーカイブ」（1 枚でも、選んだものまとめてでも）、`PATCH /api/artifacts/{slug}` の
  `archived` で、ページを消さずに `floe list` と管理ページの一覧から外す。URL では今までどおり
  開ける。管理ページは棚の「アーカイブ」で、`floe list --archived` は 5 列目を付けて、アーカイブも
  出す。アーカイブしたページを publish し直すと、一覧に戻る。
- 追加：`floe publish`。データファイル（YAML）のページを、そこに書いたテンプレートで描き、
  描いたとおりに保存して、ローカルのサーバー（`http://127.0.0.1:7325`）の URL を出す。
  サーバーが動いていなければ裏で起こす。`--link` は保存せず、ファイルをその場で登録する。
  HTML のファイルはそのまま見せ、データファイルはページを開くたびに描き、保存すると開いた
  タブを読み直す。サーバーを使うコマンド（`floe rebuild`・`list`・`rm`・`archive` も）は、
  ポートのサーバーを使えないとき（別の保存先のもの、別のディレクトリで描くもの、止まらない
  古いもの、答えないポート）、どうするかと、そのコマンドをもう一度実行するよう言って断る。
  `floe stop` は、サーバーが止まってから戻る。サーバーは、頼んで止める（サーバーが名乗る pid に
  シグナルを送らない。その pid は別のプロセスでありうる）。サーバーは途中の要求を終えてから止まる。
- 追加：`floe check` と `floe render`。データファイルを書かずに確かめ、ページを floe 無しで
  開ける HTML のファイルに書く（CI 向けに `--check`）。誤りは
  `file:line:column: message` で出し（根に足りない鍵など、ファイル全体の誤りは
  `file: message`）、確かめの 1 つの段の誤りは全部まとめて出す。
- 追加：`floe rebuild`。保存したページを、今のテンプレート・部品・テーマで描き直す。描けなく
  なったページは前のままにする。
- 追加：`floe list`・`floe rm`・`floe serve`・`floe stop` と、ブラウザの言語で英語か日本語に
  なる管理ページ（ページの一覧・編集・表示・ダウンロード）。左の棚で、すべて・お気に入り
  （すべての一覧では先頭にまとめる）・アーカイブ・タグ・種類・プロジェクトを選ぶ（狭い画面
  では 1 つの選ぶ欄にたたむ）。開いたページの上の帯で、お気に入りとアーカイブができる（ボタンはアイコンだけで、オンの間は塗る）。帯の題を押すと、開いた一覧のページが並び、探して選べる。一覧の並べ替えは、管理ページの形のメニューで、マウスでもキーでも選べる。
  タグは、1 枚の編集の画面、選んだものまとめて、`PATCH /api/artifacts/{slug}` の `tags` で
  付け、ページの題の下に出て、検索でも当たり、publish し直しても残る。キーで来たボタンや欄には
  細い灰色の輪を 1 つ出し、マウスで押したボタンには出さない。
- 追加：floe のテンプレート `report`（見出しの下に節を並べ、節ごとに見出しと部品と、その後に 1 段だけの
  小節（見出し `<h3>` と部品）を置く。見出しは、書くなら空の字にできず、小節のある節には要る）と、
  テンプレートが `floe:///parts/<name>.json` で指す 30 の部品（`floe part list` が並べる）。
  そのうち 28 は report の節が Markdown の `text`・`html` と並べて取るもの（`code`・
  `terminal`・`table`・`image`（画面の写しなど、データファイルのディレクトリの画像）から
  `findings`・`decision`・`entries`・`timeline`・`tabs`・`diagram`・`script` まで）、`cell` と `stack` はほかの部品が中に持つもの。
  部品は、自分が置かれる段を知らないので見出しを描かない。`options` と `decision` の題も見出しでなく、
  部品をどこに置いてもページの見出しの段が崩れない。
- 追加：データファイルが `theme:` で選ぶ 12 のテーマ（`default`・`soft`・`editorial`・
  `ink`・`brutal`・`blueprint`・`notebook`・`retro`・`swiss`・`washi`・`aurora`・`app`）。どれも
  CSS の変数のパレットと部品の形を持つ。部品の中（注意・手順・カード・details・tabs）の
  引用は、テーマのページの引用の形でなく、floe の引用（左の線）で描く。全部のタブを題の下に
  出す印刷では、画面で選んだタブの題をどのテーマも塗らない。
  `aurora` は、ラベンダー・桃・ミントのぼかしの地に、白いすりガラスの面と紫の差し色、丸い角。`app` は、青みの灰の地から白いカードを柔らかい影で浮かせ、
  欧文は Windows・Android のアプリの字、差し色はラズベリー。`default` と、その色を使うテーマ（`soft`・`editorial`）のページの地は、管理
  ページと同じ暖かい灰色で、字の色も管理ページと同じ、線も同じ暖かさ。terminal のプロンプト、
  code の言語の札、diff の hunk の頭は黄緑。
- 追加：`FLOE_TEMPLATES_DIR` の自分のテンプレート（`page.html`・`schema.json`・
  `example.yaml`、要るなら `page.css`・`checks.yaml`・`computed.yaml`・`words.yaml`・
  `assets/`）と、`floe template list`・`show`・`new`（埋めて使う最小のテンプレート。
  `page.html` はスマホのための viewport を持つ）・`check`。
- 追加：`FLOE_PARTS_DIR`・`FLOE_THEMES_DIR` の自分の部品・見た目・共有の schema・テーマ
  （floe のものと並べて置き、floe のものと同じ名前は付けない）と、`floe part list`・`show`・
  `new`（埋めて使う最小の部品）・`check`。部品の schema は、テンプレートと同じく floe の
  format（`html`・`markdown`・`image`）と、それを持つ共有の schema を取れる。
  共有の schema は、どれかの schema が名指すかによらず、その根から確かめる。
  部品の `part.html` は、floe の部品が使う関数（`copyButton`・`bars`・`diff`・`tree`・
  `diagram`・`script`）を呼べる。`bars` は、キーと値で書いていない項目と、
  数でないか 0 より小さい値を断る。`part.html` を走らせた text/template の誤り（schema が
  宣言していない鍵など）は、`page.html` と同じくその行と列で言い、関数が値を断る誤り
  （`num`・`bars`）は、その値の位置で言う。
  テーマの `base.css` は、テンプレートの `page.css` と同じくページに当たり、部品の中と text の
  Markdown には当たらず、テンプレートの `page.css` と見た目の下に入る。根は `:scope` と書き
  （`:root`・`html` は範囲の外）、部品の中への規則は、その部品のテーマのファイルに書く。テーマの
  `markdown.css` は、どこにある Markdown にも（部品の中にも）当たる Markdown の見た目で、部品・
  見た目・テンプレートの CSS はどれもそれに勝つ。
  自分の部品・共有の schema・テーマ・テンプレートに誤りがあると、直すまでどのページも描かない。
  部品・テーマ・テンプレートの置き場所が同じか、一方がもう一方の中にあれば、その設定を断る。
