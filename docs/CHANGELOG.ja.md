## [Unreleased]

### 追加

- 追加：`floe tag <slug>... --add <名前> --remove <名前>`。コマンドからページにタグを付け、外す。ページは順に、無いページで止まる。名前は書いたとおりに 1 つでカンマでも分けず、外す名前を先に外すので、両方に書いた名前は付いたまま。管理ページのタグのモーダルは、そこで変えたタグだけを送るようにし、その間に `floe tag` やほかのタブが書いたタグは残る。
- 追加：`details`・`tabs`・`columns` と、`entries`・`checks`・`options` の 1 件の `parts` に、`tabs`・`columns`・`html` のほかの全部の部品を置けるようにした（`options`・`steps`・`facts`・`stats`、`details` の中の `details` など）。`html` は、その `</form>` がまわりの `tabs` の form を閉じるので、置けないまま。
- 追加：部品 `options` の案に `parts` を置けるようにした。題の下、文の上に、案の絵・図・コードなどの部品を並べる。同じ段に並んだカードは部品と文の頭が揃い、題から部品まで、部品から文までは `--floe-room` で、小さい絵は元の大きさのまま描く。紙ではそのカードを途中で切らずに次のページへ送る。案の `text` は部品 `text` になり、`entries` と同じく囲んだコードを警告する。`parts` の無い options の見た目は変わらない。テーマはカードの中の間を `--cards-gap` で変える。

- 追加：`report` に目次。見出しのある節が 4 つ以上のページ、または新しい鍵 `toc` の言うとおりに、幅 1000px 以上の画面では節とその小節を節の横に置き（ページは窓の幅いっぱいになる）、スクロールに合わせて今読んでいる節に印を付ける。狭い画面では節だけを節の前に置き、紙には出さない。自分のテンプレートは見た目 `toc` と関数 `contents` で使え、`markdownLabel` はリンクを字にした Markdown の 1 行を書く。
- 追加：部品 `steps` の `tags`。手順の題の下に短い値（Markdown の 1 行か pill）を並べる。entries の札と同じ書き方で、手順を行う PR などを書ける。entries と steps は新しい見た目 `tags` で札を描き、自分の部品やテンプレートも借りられる。書かないページの見た目は変わらないが、テンプレートが塗った面（帯や、自分のテンプレートの面）の上の entries の札は、灰色でなく面の字の色になる。
- 追加：部品 `code` の `title`・`start`・`mark`。`title` は何のコードかを言葉で頭に出し、`file` と並びます。`start` はその番号から行に番号を出し、`mark` はその番号の行に、左の線、いちばん長い行の端まで届く地、スクリーンリーダーが読む言葉で印を付けます。写すボタンは番号を入れず、書いたままを写します。3 つを書かないページの見た目は変わりません。
- 追加：部品 `table` の行を、列の `id` で書けるようにした。列に `id` を持たせ、行を `{ state: 済, who: walter }` と書く。書かなかった列は空に描き、どの列の `id` でもない鍵は断る。列の順に並べる今の書き方はそのままで、1 つの表で混ぜてよい。あわせて、自分の schema の `additionalProperties` の下に部品と format を置けるようにし、floe が描く（根の `additionalProperties` は `lang` や `title` まで描くので断る）。
- 追加：部品 `stats` の `from` と `better`。`from` は前の数で、`3.1 → 1.3` と描き、下に厳密な差を、`better` の向きに従って良くなった・悪くなったの色で描く。`from` の無いページはこれまでどおり。
- 追加：タスクの状態 `archived`。ページの無いタスクもアーカイブできる。完了のタスクなら「タスクをアーカイブ」が出て、`floe work --task X --state archived` でも書ける。**タスクの一覧の置き場所は状態だけで決まる**ようになり、`floe archive` でページを全部アーカイブしてもタスクは動かず、アーカイブのタスクのページを publish し直してもタスクはアーカイブのまま未読を出す。このボタンも `--state archived` と同じくタスクだけをアーカイブし、ページはそのまま残る（ページは行か `floe archive` で別にアーカイブする）。
- 追加：タスク一覧のピンの ×。ページ一覧やページの画面へ移らずに、その場でピン止めを外せる。
- 追加：部品 `chart`。名前の並びの上の数を、線か縦の棒で、4 系列まで、0 から始まる 1 つの目盛りで描く（線は `min` で始まりを変えられる）。字はどの幅でもページの大きさのままで、数は畳んだ表にも置く。色はテーマごとの `--chart-1`〜`--chart-4`。brutal・blueprint・notebook・retro・washi は線と棒の形も変える。
- 追加：部品 `checks`。調査やテストで確かめたことと実際の結果を、OK・NG・未確認、確かめ方とともに書いた順に描き、上に結果ごとの数を出す。
- 追加：タスク一覧の上の右の「＋ タスクを追加」。タスク ID とタイトルで今のプロジェクトにタスクを作り、未着手の一覧へ移って新しい行に色を付ける。すでにある ID なら「タスクを開く」でそのページへ移る。どのプロジェクトにもタスクが無い画面にも同じボタンを置き、プロジェクトを選べる。上の「ページ一覧｜タスク一覧」の切り替えは、タスクが 0 件でも出すようにし、タスクが無い画面の文も直した。タスクが無い画面とページ一覧の空の画面から、コマンドの行を消した
- 追加：部品 `asks`。読み手に判断を頼む問いを、Q1、Q2 … の番号で、案、勧めと理由、決める人、決まったら `decided` とともに描く。`handoff` の `asks` もこの部品で描くので、問いはカードになり、勧めの案に枠が付き、`decided` も書け、頭の数は未決の問いの数になる。
- 追加：タスクのページで親を付ける・変える・外す操作。「親のタスク」の「＋ 追加」は今あるタスクを親にするか、新しい親を同じ書き込みで作り、「変更」は親を移し、親や子の行の右のボタンはその子をすぐ外す。外したときと変えたときは、トーストの「元に戻す」で戻せる。画面から書くとき、その間に別のセッションが親を変えていれば断り、タスクを読み直す。
- 追加：部品 `image` に `caption` を足した。絵の下に出す 1 行の Markdown。列に収めるために縮んで描かれた絵は、図と同じく拡大できる（上の道具の並び、Ctrl / ⌘ + ホイール、ピンチ、`+ - 0` のキー。拡大中はドラッグか矢印キーで動かす。印刷では全体）。自分の部品も、関数 `{{zoom}}` と見た目 `zoom` で同じに拡大できる。
- 追加：管理ページの字のあるボタンを 1 つの形に揃えた（角は小さく、細い枠、高さ 2rem、モーダルの下は 2.25rem。丸い形はアイコンのボタンに残す）。「タスクを設定」と「子のタスクを追加」の欄を「タスク ID」「タイトル」にし、「タスクを設定」の段の欄を「段階」にして、どれにも例を出し、新しいタスクはタイトルが要る。古い表示のまま保存したときは断り、タスクを読み直す。
- 追加：部品 `columns`。前と後の画面など、部品を横に並べて同時に見せる。列は、省ける `title` とその下の `parts`（`details` と同じ部品）で、どれも同じ幅。幅が足りなければ縦に並ぶ。
- 追加：タスクの状態 `todo`（未着手）。新しいタスクは、どの道でも未着手で始まる。左の列は流れの順に未着手、作業中、確認待ち、完了、アーカイブで（開いたときは今のまま確認待ち）、未着手は未着手になった新しい順に並ぶ。「済み」の字は「完了」にした（値の `done` は変わらない）。
- 追加：子のタスク。`floe work --task "#130" --parent "#123"`（ページと一緒にも：`floe work design-notes --task "#130" --parent "#123"`）か「タスクを設定」の親の欄で、同じプロジェクトのタスクを 1 段だけ親にでき、タスクのページの「＋ 追加」で新しい子を作るか、今あるタスクを子にできる。`--parent ""` で外し、子が残っている間は `--forget` を断る。タスク一覧の子の行に親の名前、親の行に子の数が出て、タスクのページはページの上に子か親を並べる。自分のページが無い親は、子でアーカイブへ移るかが決まる。
- 追加：タスクの画面。`floe work` で、ページがどのタスクにあるか、段、ピン止めと、タスクの状態・外のリンク・題・段の順を書き、タスクは保存先の `tasks.json` に持つ。ページの印は、公開し直しても、名前を変えても、描き直しても残る。タスク一覧（`/tasks`）は、1 つのプロジェクトのタスクを状態で分け、待ちの長い順に、段・ページの数・未読・リンクを並べ、上にそのプロジェクトのピン止めしたページを出す。ページをタスクに載せるかピン止めすると、ロゴの横に切り替えが出る。行を押すとタスクのページを開き、段ごとのページ、状態の変更、完了のタスクのアーカイブができる。ページの「…」からピン止め、タスクを開く、タスクと段と URL の設定ができ、ページ一覧の行にタスクとピン止めのバッジが出る。画面からタスクを書くとき（状態、アーカイブ、親、タスクを設定）、画面が読んだ後にタスクが書かれていれば断り、タスクを読み直す。
- 追加：図の線の `via` の点に、片方の軸だけの `{ x: 710 }`・`{ y: 218 }` を足した。もう片方は前の点の値（最初の点は線の始まりの中心の値）で、部品の位置を写さずに書ける。docs に、選んだ曲がり角だけを書くことと、省けない点を書いた。
- 追加：部品 `entries` の項目に `parts`。`details` と同じ部品の並びを `text` の下に置け、項目の中のコードを `code`・`terminal` で、ファイル名やプロンプトの下に写すボタン付きで描ける。
- 追加：図の `graph` の箱とアイコンに `with: <名前>` を足した。線を描かずに、名前の箱かアイコンと同じ段に立てる（別のまとまりの箱とも書ける）。その箱へ入る箱からの線は段を決めないので、線を図の意味のまま書ける（サーバーからゲートウェイへ上向きなど）。線 25 本の AWS の図は、枠の外の箱が枠の横に立たなくなり、2136×1440 が 1704×1407 になる。
- 追加：`floe diagram inspect` がデータファイルを読むようにした。根に鍵 `template` があるファイルは、テンプレートの schema で確かめた後の図を、`details`・`tabs` の中も含めて書いた順に出し、ページは描かない。枠の見出しの行 `the heading of frame "F" x,y WxH` も足し、見出しを通ると断られた線をどこまで動かせばよいかが分かるようにした。
- 追加：向かい合う 2 つの辺に共通の高さがある線を、真ん中の差で曲げず、まっすぐ引く。手で書いた線は、まっすぐな線が何にも当たらないとき。graph のアイコンの線は、アイコンを動かしても届かないとき、辺に 1 本だけの端が点から最大 12 ずれて立つ。それで誤りが出るとき（場所を書いていないラベルが何かに当たる、など）は、その図の線はどれも今のまま。
- 追加：手で書いた線の等分。箱・アイコン・表・枠の 1 つの辺に来る n 本の線の端は、辺の真ん中でなく、辺を n+1 等分した点に立つ。まっすぐな線はまっすぐのまま。当たる線は真ん中のままで、ラベルが邪魔なときは動かすと分かれる。1 点から分けたいときは `via` か `tree` で書く。
- 追加：図の `graph` の線の等分。箱の 1 つの辺に来る n 本の線の端は、道を決めた格子の列でなく、辺を n+1 等分した点に立つ。まっすぐな線はまっすぐのまま。何かに当たる、交差が増える、ほかの線のすぐ脇を通る端は今の場所のまま。箱の輪と `level` の線は数えない。
- 追加：管理ページに、保存したページの 2 つの版の差分の画面。見出しごとの字の違いを、左右に並べる・まとめて表示・変更のみで見せる。2 つの版を選べ、幅を変えたり隠したりできる目次と、`n` `p` で変わった所を移れる。ページの上の「差分」と `d` で開き、新しい版を初めて開くと、前に読んだ版から何節変わったかを知らせる。開いても既読にならない。ページの HTML は持ち込まず、サーバーが版を字にして、画面は字として描く。
- 追加：図の `graph` の節に `icon: { name, icon, label }`。AWS のようなアイコンの構成図を、graph の `x`・`y` のほかに座標なしで書ける。アイコンは枠なしの 48 の正方形のままで、1 つの辺に来る n 本の線は、辺を n+1 等分した点で終わる。`group` と帯（レーン）も `icon` を持ち、枠の角に描く。見本は `floe diagram example aws-graph`。
- 追加：ページ検索のモーダル。`Ctrl+K`（`⌘K`）はどこからでも、`/` は全画面で開き、スマートフォンの全画面では虫眼鏡で開く。題・説明・URL 名・プロジェクト・パス・テンプレート・タグで検索し、
  アーカイブしたものは後ろに出す。行を開くと全画面に移り、選んでいる行には行と同じボタンで操作できる。キーボードショートカットのモーダルも足した（`?` か上の帯のボタン）。
  全画面では `h` で一覧へ戻る。ページの中を押した後も `j` `k` `h` `?` `/` `Ctrl+K` が働く（リンクとフォルダの中の HTML は、自分で字のキーを使うことがあるので `Ctrl+K` だけ）。
- 追加：保存したページを未読に戻す操作。開いたページが既読になると、トーストに「未読に戻す」が 8 秒出る。ページの「…」のメニューにもある。
  開く前の見た目に戻り（`DELETE /api/artifacts/{slug}/read`）、もう一度開くと既読になる。`POST /api/artifacts/{slug}/read` は、最新の版まで読んだときに `{"cleared": true}` を返す。
- 追加：保存したページのうち、見る人がどこまで読んだかの記録。保存先の `reads.json` に持つ。枠で開いたページが、返した版を
  枠へ知らせ、枠が `POST /api/artifacts/{slug}/read` で送る。`GET /api/artifacts` は保存したページごとに `news`（まだ見て
  いないページは `new`、読んだ版より後の版があれば `version`）と `version`（最新の版の番号）を返す。floe が `reads.json` を
  初めて書く前からあるページは、読んだものとして扱う。`GET /api/artifacts` は、保存したページとデータファイルのリンクの
  `template`（テンプレートの名前）も返す。前に publish したページの meta.json には `floe rebuild` が書く。
- 追加：図の部品 `axis` の `labels: between`。目盛りの字を、その目盛りと右隣の目盛り（最後の目盛りは `x2`）の真ん中に置く。
  週の名前を週の真ん中に置くときなどに使う（既定の `labels: at` は、今までどおり目盛りの位置）。
- 追加：テンプレートがページを中央にそろえる列を、class `floe-column` の要素に置けるようにした。幅は `--column-width`
  （テンプレートが置かなければパレットの `--page-width`）で、左右に `--page-pad` をあけ、テンプレートの `page.css` が勝つ。
  1 列のページは `:scope { --column-width: var(--text-width); }` を置く。floe のテンプレートは、列を自分で書く代わりにこれを使う。
- 追加：テーマの `markdown.css`。ページの上、text の中、部品の中の、どこにある Markdown にも
  当たる Markdown の見た目（引用、見出し）。floe のテーマは引用（retro は見出しの縞も）をここで
  描く。部品・見た目の名前に `markdown` は使えない。
- 追加：図の部品 `graph`。箱と、それをつなぐ線を名前で書くと、floe が段に並べ
  （`direction: down`・`right`）、段の中を線の交わりが少ない順に並べ、線を箱の辺の
  別々の点の間に直角に引く。線はできるだけまっすぐに引き、線の入る場所が 1 列足りない箱は
  横の空いた所へ広がり、段を越える線は、自分の列を離れる所で 1 回だけ曲がる。線の `label` は線の上に、地で線を切って立ち、いちばん長い区間の真ん中が空いていなければずれ、
  空きが無ければ floe が線を曲げずに場所を作る。箱から同じ箱へ戻る線は、graph の線が使わない辺に出る
  輪になる。節の `group`（まとまり。入れ子にできる）は、中の箱をどの段でも隣に並べ、
  `label` を見出しにした `frame` の枠で囲み、線はまとまりも端にでき、枠の上か下の辺で終わる。
  `nodes` の代わりに `lanes` に書いたまとまりは帯（レーン）になり、graph の端から端まで、書いた順に、上と下を
  そろえて並ぶ。`level: true` と書いた線は、2 つの箱を同じ段に立て、向かい合う辺の間を
  まっすぐ結ぶ。2 つの箱は、同じまとまりの中で書いた順に隣に並ぶか、別々の帯の直下で、
  それぞれ相手の側の帯の端に立つ。2 つの箱の間に何かが立つ線と、箱の輪の辺を使う線は断る。
  1 つの graph は箱とまとまり 200・線 400 まで、図の全部の graph の線が端と端の間で越える段は
  合わせて 4000 まで。図の見本 `flow`・`state`・`swimlane` はこれで描く。
- 追加：部品と見た目の `part.yaml` の `marks:`。どの要素が左に印のある行かを、`box`・
  `items`（子の `li`）・`joined`（次への線つき）で言う。floe が行を層 `floe.marks` に
  1 つ並べ（印の置き場所と大きさ）、印は部品が描く。部品の見た目の連なりで `marks:` を
  2 回書くと、`floe part check` が断る。
- 追加：見た目 `marked`。並びの項目の前の字を行の印にする。decision・options・checklist・
  handoff の済んだ作業が借りる。
- 追加：見た目 `numbered` の項目の `data-floe-mark`。`ring` は縁を tone に、`solid` は丸と
  線を tone で塗る。
- 追加：パレットの `--quiet`（箱の中の静かな地）。表の頭、棒の溝、キーが
  読む。
- 追加：パレットの角の丸さの変数 `--radius`・`--radius-small`・`--radius-pill`（どれも
  1 つの長さ）。箱、箱の中の小さな升、札の丸さ。部品・テンプレート・floe の base・テーマが
  読み、テーマは丸さをパレットだけで決める。
- 追加：静かな tone `muted`（`--muted-soft` の地に `--muted` の色）。tone を書ける
  所（note、pill、表の pills、bars、stats、timeline、図）のどこでも書ける。
  adr の deprecated・superseded、postmortem の重さ low、fields の型はこの色で描く。
- 追加：`--tone-fill`。テーマが tone を塗る色で、パレットの `--<tone>-fill`
  （`--good-fill`）から、無ければその tone の `-soft` から。
- 追加：図の `width` と `height` を省けるようにした。省くと、キャンバスは描いた
  ものの右（下）の端まで広がり、さらに 20 空ける。左上は 0, 0 のまま。`raw` の
  SVG は測らないので、`raw` を使う図は両方を書く。

### 変更

- 変更：`report` の `eyebrow` を、`lead` と節の見出しと同じ Markdown の 1 行にした。バッククォートのコード、太字、リンクを描き、裸の URL とメールのアドレスはリンクになる（IP や localhost の URL はならない）。タグに見える字（`<prefix>`、`Vec<u8>` など）は除き、`*`・`_`・`~` などの記号は読む（`~` は 1 つでも組になり、`2026-11-01~11-08` は間が取り消し線になる）ので、字として書くならバッククォートで囲む。
- 変更：管理ページのタグの付け方を変えた。一覧の右・全画面・タスクのページで開いたページは、帯の下にタグの行を出し、そのボタンでそのページだけのタグのモーダルを開く。行と帯の「…」にも「タグ」を足した。タグを変えるのは、選択したページにも使うこのモーダル 1 つだけで、編集のモーダルからタグの入力欄を外した（ほかの欄を直したときに、読点やカンマを含むタグが割れることもなくなった）。モーダルの検索欄の Enter は、絞り込みで残ったタグが 1 つならそれを付け、ほかは名前を新しいタグにする。全画面の印刷にはタグの行を出さない。
- 変更：`options`・`facts`・`stats`・`bars`・`keys`・`timeline`・`asks` を、置いた場所の幅で並べるようにし、案のカードの中などの狭い場所でもはみ出さないようにした。カードの列は場所より広くならず、`keys`・`timeline` は自分の幅で狭い並びに替わり（そのため、576px までだった窓の幅が 640px ほどまでになる）、`asks` の札は折り返し、`bars` の名前と値はそれぞれ 40% までで折り返して、長い名前でも棒が細くならない。`timeline` の狭い並びの点と字の間は広い並びと同じになり、前より 4px 詰まる。
