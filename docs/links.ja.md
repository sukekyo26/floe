# リンクしたファイルとフォルダ

`floe publish --link` は、ページを保存せず、HTML のファイル・データファイル・フォルダをその場で登録します。登録できるもの、断るもの、付く slug は [commands.ja.md](commands.ja.md#リンクしたファイル) にあります。

## HTML のファイル

HTML のファイルはそのまま見せます。floe は周りに何も足さないので、自分のページやほかの道具が作ったページが、書いたとおりに出ます。その相対の参照（CSS・スクリプト・画像）のため、ディレクトリの下のファイルも配信します。ファイルを保存すると、開いたタブを読み直します。

## データファイル

リンクしたデータファイルは、リンクしたときの `--theme` で、ページを開くたびに描きます。リポジトリで書いているページを、書きながら読めます。

- データファイル、自分の部品・テーマ・テンプレートを保存したとき、またアイコンを取ってきたとき、開いたタブを読み直します。見せる画像を保存しただけでは読み直しません。データファイルを保存し直すか、タブを読み直してください。
- 誤りがあれば、タブはページの代わりに誤りを見せ、直して保存するとページに戻ります。
- ディレクトリのものは配信しません。画像はページの中にあります。ダウンロードは描いたページで、CSP を `<meta>` に入れます。
- 一覧の題は `title:` で、そのたびに読みます。

## フォルダ

リンクしたフォルダは、管理ページの「フォルダ」のタブの 1 行です。その URL（`/a/<slug>/`）は、そのタブをフォルダを開いた形で開きます。

- 行を開くと、フォルダの直下のもの（ディレクトリ、次に HTML のファイル（`.html`・`.htm`）、どちらも名前の順）が出ます。ディレクトリも同じく開け、開いた所だけを読むので、ファイルが何千あるフォルダでも、費用は開いたディレクトリの分だけです。開いた所は、URL でなくブラウザが覚え、読み直しても開いたままです。
- `.` で始まる名前（`.git`・`.drafts`）は出しません。フォルダの外へ出る symlink と、ふつうのファイルとディレクトリのほかのものも出しません。ディレクトリへの symlink は開きません。フォルダの下のファイルは、リンクした HTML のファイルのディレクトリと同じ決まりで配信します。
- 1 つのディレクトリで出すのは、名前の順に最初の 1000 項目までです。その下の 1 行が、全部でいくつあるかを言います。
- フォルダのページは枠（`/a/<slug>/?file=<パス>`）でフォルダの題の下に開き、左にフォルダの木（ページのある所を開いた形）が出ます。木の境目を引くか、そこで ← → Home End を押すと幅が変わり（160px から、480px か窓の半分まで）、頭のボタンで隠せます。幅と隠したかはブラウザが覚えます。木を隠したときと狭い画面（木はページの上に重なって開く）では、バーから同じディレクトリのページを選べます。題はファイルの名前で、並べるために中は読みません。
- フォルダの中で足した・消した・名前を変えたものは、次に一覧を読んだときに出ます。お気に入り・アーカイブ・タグ・題はフォルダの行が持ち、中のページは持ちません。
- リポジトリの中のフォルダの題は、リポジトリの中の場所（`docs`・`docs/v1`）で、リポジトリの外のフォルダは、フォルダの名前（`handbook`）です。
