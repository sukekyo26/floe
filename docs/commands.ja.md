# コマンド

`floe` の全コマンドのリファレンスです。

## 早見表

| コマンド | 用途 |
|---|---|
| `floe publish <file.html>` | ページを保存し（`--link` ならその場所のまま登録し）、URL を出す |
| `floe list` | ページを新しい順に出す |
| `floe rm <slug>...` | ページを消す |
| `floe serve` | サーバーを前面で動かす |
| `floe stop` | 裏で動いているサーバーを止める |
| `floe version` | 版を出す（`floe --version` でも可） |
| `floe help [command]` | ヘルプを出す（Cobra の組み込み） |

---

## `floe publish <file.html>`

ページを保存し、URL（`http://127.0.0.1:7325/a/<slug>/`）を stdout に出します。サーバーが動いていなければ、先に裏で起動します。新しい URL 名はブラウザでも開きます。公開し直したときは開いているタブが自分で再読み込みするので、開きません。

相対パスの `<file.html>` は、作業ディレクトリを基準に解決します。

### フラグ

| フラグ | 説明 |
|---|---|
| `--link` | ファイルをコピーせず、その場所のまま登録する（[リンク](#リンク)を参照） |
| `--slug <name>` | URL 名。英小文字・数字・ハイフンで 64 文字まで。既定はファイル名で、`index.html` はディレクトリ名を使う |
| `--title <text>` | 一覧に出すタイトル。既定はページの `<title>`、無ければ最初の `<h1>`、それも無ければ URL 名。空の値は使い方の誤り |
| `--description <text>` | 一覧に出す説明 |
| `--lang <tag>` | 本文だけの HTML を包む言語。BCP 47 の言語タグ（`en`・`ja`・`pt-BR`）。既定は `en`、その URL 名で前に指定した言語があればそれ |
| `--force` | 別のプロジェクトから公開したページや、別のファイルのリンクを置き換える |

### 本文だけの HTML

doctype・`<html>`・`<head>`・`<body>`・`<title>` のどれも無いファイルは、組み込みの雛形で包み、`<html lang>` を `--lang` にします。文書として整ったファイルはそのまま保存します。

### プロジェクトと上書き

ページは、公開したプロジェクトのものになります。プロジェクトは git の `origin` の URL にあるリポジトリ名、無ければリポジトリのディレクトリ名、それも無ければ作業ディレクトリの名前です。リンクは、ファイルのあるディレクトリから決めます。

- 同じプロジェクトから同じ URL 名で公開すると、上書きします。そのことを stderr に出し（`「plan」を更新しました（前回の公開は …、タイトルは「…」）`）、タイトルが変わっていれば別の `--slug` を勧める警告も出します。終了コードは 0 のままです。
- 別のプロジェクトから公開した URL 名は、`--force` が無ければ断ります。`--force` で置き換えると、前のページの内容は何も引き継ぎません。
- 公開し直しても、管理画面で設定したもの（タイトル・プロジェクト・お気に入り）、説明、言語、作成日時は残ります。`--title`・`--description`・`--lang` を指定すれば、そちらが優先されます。

### リンク

`--link` は、ファイルをその場所のまま配信します。リクエストのたびに読み直すので、ファイルを保存すれば開いているタブも更新されます。相対パスで参照するファイル（CSS・スクリプト・画像）のために、そのディレクトリの配下も配信します。

- 登録できるのは、通常の `.html` / `.htm` ファイルだけです。
- ホーム直下の隠しディレクトリ（設定や鍵の置き場）の中にあるファイルは断ります。
- `/` の直下やホームの直下にあるファイルは、ディレクトリ全体が公開されてしまうので断ります。
- `--slug` を付けずに登録すると、同じファイルの URL 名があればそれを使い、無ければ `name`・`name-2`・`name-3` … のうち空いている最初のものを使います。
- 別のファイルが使っている URL 名は、`--force` が無ければ断ります。

## `floe list`

ページを新しい順に出します。各行はタブ区切りの 4 列で、更新日時（ローカル時刻、`YYYY-MM-DD HH:MM`）、URL 名、タイトル、リンクのパス（保存したページは空）です。

## `floe rm <slug>...`

指定した順にページを消します。失敗したところ（無いページなど）で止まります。リンクは登録を消すだけで、ファイル自体は残ります。

## `floe serve`

サーバーを前面で動かし、`127.0.0.1` で SIGTERM か SIGINT を受けるまで配信します。`floe publish` も同じサーバーを裏で起動するので、主にエラーを確かめるときに使います。

## `floe stop`

裏で動いているサーバーを止めます。動いていなければ「サーバーは動いていません」と出し、終了コード 0 で終わります。

---

## サーバー

- `floe publish` は、サーバーが動いていなければ起動し、動いていればそれを使います。2 つの publish が同時に起動しようとしても、どちらも立ち上がった方のサーバーを使います。
- floe を入れ直すと（別の版か、ビルドし直したバイナリ）、次の publish が動いているサーバーを入れ替えます。
- サーバーは `floe stop`・ログアウト・再起動まで動き続けます。
- 待ち受けは `127.0.0.1` だけです。ほかのホスト名（DNS rebinding 対策）や、ほかのサイトからの書き込みは断ります。
- ページは sandbox の中で動くので、ページのスクリプトから管理画面の API には届きません。

## 環境変数

| 変数 | 説明 |
|---|---|
| `FLOE_DIR` | ページの保存先。既定は `$XDG_DATA_HOME/floe`、無ければ `~/.local/share/floe`。artifact スキルと同じ形式なので、互いの保存先を読める |
| `FLOE_PORT` | ポート（既定は `7325`）。1 から 65535 の 10 進数 |
| `FLOE_LANG` | メッセージの言語（`en`・`ja`）。無ければ `LC_ALL`、`LC_MESSAGES`、`LANG` の順に見る。カタログの無い言語は飛ばす。既定は英語 |
| `BROWSER` | 新しいページを開くコマンド。既定は macOS なら `open`、それ以外は `wslview` か `xdg-open` |

管理画面は、代わりにブラウザの言語に従います。Cobra 自身のエラー（知らないフラグやコマンド）と `--help` は英語です。

## 終了コード

| コード | 意味 |
|---|---|
| `0` | 成功 |
| `1` | 失敗（断られた公開、無いページ、使われているポートなど） |
| `2` | 使い方の誤り（知らないフラグやコマンド、引数の不足、空の `--title`） |
